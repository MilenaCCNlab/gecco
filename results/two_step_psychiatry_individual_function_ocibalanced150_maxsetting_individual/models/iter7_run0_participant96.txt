Here are 3 new cognitive models based on the participant's data and previous feedback. 

The participant exhibits extremely long streaks of the same Stage 1 choice (e.g., choosing spaceship 0 continuously from trial 12 to 164, despite receiving many 0-coin rewards). This suggests their choices are heavily influenced by a mechanism that overrides short-term negative feedback. We can model this by combining asymmetric learning rates (where negative prediction errors are ignored or learned very slowly) with mechanisms that accumulate choice history (like a choice kernel) or separate inverse temperatures for each stage.

### Model 1: Asymmetric Learning + Eligibility Trace + Decay
This model builds on the best model so far by adding an eligibility trace (`lam`). The eligibility trace allows the prediction error from Stage 2 (the actual reward) to directly update the Stage 1 value. This can help explain why the participant eventually shifts their Stage 1 behavior after accumulating enough negative feedback at Stage 2.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Model 1: Asymmetric learning rates, eligibility trace, perseveration, and unchosen decay.
    Combines the best features (asymmetric learning, unchosen decay) with an eligibility trace 
    (lam) to allow stage 2 prediction errors to update stage 1 values directly.
    
    Bounds:
    alpha_pos: [0, 1] - learning rate for positive prediction errors
    alpha_neg: [0, 1] - learning rate for negative prediction errors
    beta: [0, 10] - inverse temperature
    w: [0, 1] - model-based weight
    pers_1: [-5, 5] - stage 1 perseveration bonus
    pers_2: [-5, 5] - stage 2 perseveration bonus
    lam: [0, 1] - eligibility trace parameter
    decay_rate: [0, 1] - rate at which unchosen stage 2 values decay toward 0.5
    """
    alpha_pos, alpha_neg, beta, w, pers_1, pers_2, lam, decay_rate = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    
    q_stage1_mf = np.ones(2) * 0.5
    q_stage2_mf = np.ones((2, 2)) * 0.5
    
    last_action_1 = -1
    last_action_2 = -np.ones(2, dtype=int)

    for trial in range(n_trials):
        # Stage 1 policy
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        pers_bonus_1 = np.zeros(2)
        if last_action_1 != -1:
            pers_bonus_1[last_action_1] = pers_1
            
        q1_total = beta * q_stage1_net + pers_bonus_1
        q1_total -= np.max(q1_total)
        exp_q1 = np.exp(q1_total)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]

        # Stage 2 policy
        pers_bonus_2 = np.zeros(2)
        if last_action_2[state_idx] != -1:
            pers_bonus_2[last_action_2[state_idx]] = pers_2
            
        q2_total = beta * q_stage2_mf[state_idx] + pers_bonus_2
        q2_total -= np.max(q2_total)
        exp_q2 = np.exp(q2_total)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # Stage 1 update
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        alpha_1 = alpha_pos if delta_stage1 >= 0 else alpha_neg
        q_stage1_mf[action_1[trial]] += alpha_1 * delta_stage1

        # Stage 2 update
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        alpha_2 = alpha_pos if delta_stage2 >= 0 else alpha_neg
        q_stage2_mf[state_idx, action_2[trial]] += alpha_2 * delta_stage2
        
        # Eligibility trace update for stage 1 based on stage 2 prediction error
        q_stage1_mf[action_1[trial]] += alpha_2 * lam * delta_stage2

        # Decay unchosen options
        unchosen_action_2 = 1 - action_2[trial]
        q_stage2_mf[state_idx, unchosen_action_2] = (1 - decay_rate) * q_stage2_mf[state_idx, unchosen_action_2] + decay_rate * 0.5
        
        other_state = 1 - state_idx
        q_stage2_mf[other_state, 0] = (1 - decay_rate) * q_stage2_mf[other_state, 0] + decay_rate * 0.5
        q_stage2_mf[other_state, 1] = (1 - decay_rate) * q_stage2_mf[other_state, 1] + decay_rate * 0.5

        last_action_1 = action_1[trial]
        last_action_2[state_idx] = action_2[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Asymmetric Learning + Choice Kernel
Instead of a simple lag-1 perseveration (which only looks at the immediately preceding trial), this model uses an auto-regressive choice kernel. The choice kernel builds up inertia over consecutive identical choices. This is highly suitable for capturing the participant's behavior of sticking to the same spaceship for over 100 trials, as the choice trace will saturate and dominate the decision-making process.

```python
def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """
    Model 2: Asymmetric learning rates with Choice Kernel (auto-regressive choice trace).
    Instead of lag-1 perseveration, this uses a choice kernel that builds up over time,
    which can explain very long streaks of the same choice despite negative feedback.
    
    Bounds:
    alpha_pos: [0, 1] - learning rate for positive prediction errors
    alpha_neg: [0, 1] - learning rate for negative prediction errors
    beta: [0, 10] - inverse temperature
    w: [0, 1] - model-based weight
    ck_weight_1: [-5, 5] - weight of the choice kernel in stage 1
    ck_weight_2: [-5, 5] - weight of the choice kernel in stage 2
    ck_decay: [0, 1] - decay rate of the choice kernel trace
    """
    alpha_pos, alpha_neg, beta, w, ck_weight_1, ck_weight_2, ck_decay = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    
    q_stage1_mf = np.ones(2) * 0.5
    q_stage2_mf = np.ones((2, 2)) * 0.5
    
    ck_1 = np.zeros(2)
    ck_2 = np.zeros((2, 2))

    for trial in range(n_trials):
        # Stage 1 policy
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        q1_total = beta * q_stage1_net + ck_weight_1 * ck_1
        q1_total -= np.max(q1_total)
        exp_q1 = np.exp(q1_total)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]

        # Stage 2 policy
        q2_total = beta * q_stage2_mf[state_idx] + ck_weight_2 * ck_2[state_idx]
        q2_total -= np.max(q2_total)
        exp_q2 = np.exp(q2_total)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # Action value updates
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        alpha_1 = alpha_pos if delta_stage1 >= 0 else alpha_neg
        q_stage1_mf[action_1[trial]] += alpha_1 * delta_stage1

        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        alpha_2 = alpha_pos if delta_stage2 >= 0 else alpha_neg
        q_stage2_mf[state_idx, action_2[trial]] += alpha_2 * delta_stage2

        # Choice kernel updates
        ck_1 = ck_1 * ck_decay
        ck_1[action_1[trial]] += 1.0 - ck_decay
        
        ck_2[state_idx] = ck_2[state_idx] * ck_decay
        ck_2[state_idx, action_2[trial]] += 1.0 - ck_decay

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 3: Asymmetric Learning + Separate Stage Betas + Decay
This model separates the inverse temperature (`beta`) for Stage 1 and Stage 2. A participant might be highly deterministic in Stage 1 (sticking to one spaceship reliably) but much more exploratory or stochastic in Stage 2 (switching between aliens). Giving the model separate `beta` parameters allows it to better capture this dichotomy without needing to inflate the perseveration parameters.

```python
def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """
    Model 3: Asymmetric learning rates, separate inverse temperatures for Stage 1 and 2,
    perseveration, and unchosen option decay.
    Separating beta allows the model to capture different levels of stochasticity 
    in the two stages, which is useful given the extreme streaks in Stage 1.
    
    Bounds:
    alpha_pos: [0, 1] - learning rate for positive prediction errors
    alpha_neg: [0, 1] - learning rate for negative prediction errors
    beta_1: [0, 10] - inverse temperature for Stage 1
    beta_2: [0, 10] - inverse temperature for Stage 2
    w: [0, 1] - model-based weight
    pers_1: [-5, 5] - stage 1 perseveration
    pers_2: [-5, 5] - stage 2 perseveration
    decay_rate: [0, 1] - rate at which unchosen stage 2 values decay toward 0.5

        q1_total -= np.max(q1_total)
        exp_q1 = np.exp(q1_total)

        p_choice_1[trial] = probs_1[action_1[trial]]

        q_stage2_mf[other_state, 0] = (1 - decay_rate) * q_stage2_mf[other_state, 0] + decay_rate * 0.5
        q_stage2_mf[other_state, 1] = (1 - decay_rate) * q_stage2_mf[other_state, 1] + decay_rate * 0.5
```
