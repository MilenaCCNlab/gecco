Here are 3 new cognitive models that introduce different well-established psychological mechanisms for learning and decision-making in the two-step task. Each model strictly follows the provided template structure for the first choice while filling in the blanks for the second choice and the action value updates.

### Model 1: Separate Softmax Temperatures (Exploration Rates)
This model introduces separate inverse temperature parameters for Stage 1 and Stage 2. Participants often exhibit different levels of exploration or noise in their choices between the two stages (e.g., being more deterministic in Stage 1 but exploratory in Stage 2). 

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Cognitive model 1: Separate softmax temperatures for Stage 1 and Stage 2.
    Stage 1 decision uses `beta`, while Stage 2 decision uses `beta_2`. This allows 
    the model to capture different levels of choice stochasticity across the two stages.
    
    Bounds:
    learning_rate: [0, 1]
    beta: [0, 10]
    beta_2: [0, 10]
    """
    learning_rate, beta, beta_2 = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        exp_q1 = np.exp(beta * q_stage1_mb)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta_2 * q_stage2_mf[state_idx])
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        
    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Fictitious Updating for Unchosen Actions
This model incorporates counterfactual (or fictitious) updating. When the participant chooses an alien and receives an outcome, they might infer that the *other* alien on the same planet would have yielded the opposite outcome. This is a common heuristic when resources are perceived as competitive or inversely correlated.

```python
def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """
    Cognitive model 2: Fictitious updating for the unchosen action in Stage 2.
    The chosen action is updated with the actual reward received. The unchosen action 
    in the same state is updated assuming it would have yielded the opposite reward.
    
    Bounds:
    learning_rate: [0, 1]
    fictitious_lr: [0, 1]
    beta: [0, 10]
    """
    learning_rate, fictitious_lr, beta = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        exp_q1 = np.exp(beta * q_stage1_mb)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta * q_stage2_mf[state_idx])
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        
        # Fictitious update for the unchosen action in the same state
        unchosen_a2 = 1 - action_2[trial]
        fictitious_reward = 1 - reward[trial]
        delta_fict = fictitious_reward - q_stage2_mf[state_idx, unchosen_a2]
        q_stage2_mf[state_idx, unchosen_a2] += fictitious_lr * delta_fict
        
    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 3: Global Forgetting (Decay)
Because reward probabilities drift slowly over time, participants might assume that unchosen options are losing their value. This model implements a global decay mechanism where the Q-values of all unchosen actions naturally decay towards 0 over time.

```python
def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """
    Cognitive model 3: Forgetting (decay) of all unchosen actions in Stage 2.
    The chosen action's value is updated normally via prediction error. All other 
    actions (including those in the unvisited state) slowly decay towards 0.
    
    Bounds:
    learning_rate: [0, 1]
    decay_rate: [0, 1]
    beta: [0, 10]
    """
    learning_rate, decay_rate, beta = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        exp_q1 = np.exp(beta * q_stage1_mb)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta * q_stage2_mf[state_idx])
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        
        # Decay all unchosen actions
        for s in range(2):
            for a in range(2):
                if not (s == state_idx and a == action_2[trial]):
                    q_stage2_mf[s, a] *= (1.0 - decay_rate)
        
    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```
