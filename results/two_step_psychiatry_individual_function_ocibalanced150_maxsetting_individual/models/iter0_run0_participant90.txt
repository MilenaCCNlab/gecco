### Model 1: Standard Q-Learning
This model implements a standard Model-Free Q-learning update for the second stage. The first stage choice remains purely Model-Based as defined in the template.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Model 1: Standard Q-learning for both stages.
    Stage 1 uses a pure Model-Based policy as specified in the template.
    Stage 2 uses a standard Model-Free policy.
    
    Bounds:
    learning_rate: [0,1] - Rate at which prediction errors update Q-values.
    beta: [0,10] - Inverse temperature for the softmax choice rule.
    """
    learning_rate, beta = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        exp_q1 = np.exp(beta * q_stage1_mb)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta * q_stage2_mf[state_idx])
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        # Action value updating for choice 1
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        # Action value updating for choice 2
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Asymmetric Learning Rates
Humans often learn differently from better-than-expected outcomes compared to worse-than-expected outcomes. This model incorporates asymmetric learning rates for positive and negative prediction errors. 

```python
def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """
    Model 2: Q-learning with asymmetric learning rates for positive and negative prediction errors.

            q_stage2_mf[state_idx, action_2[trial]] += lr_pos * delta_stage2

            q_stage2_mf[state_idx, action_2[trial]] += lr_neg * delta_stage2
```

### Model 3: Choice Decay (Forgetting)
In restless bandit tasks, participants often slowly "forget" the value of unchosen options, causing their Q-values to decay toward zero. This model captures that dynamic by decaying the values of all unchosen aliens on every trial.

```python
def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """
    Model 3: Q-learning with decay (forgetting) for unchosen options.
    Stage 1 uses a pure Model-Based policy as specified in the template.
    Stage 2 uses a Model-Free policy.
    
    Bounds:
    learning_rate: [0,1] - Rate at which prediction errors update chosen Q-values.
    decay_rate: [0,1] - Rate at which unchosen Q-values decay towards zero.
    beta: [0,10] - Inverse temperature for the softmax choice rule.
    """
    learning_rate, decay_rate, beta = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        exp_q1 = np.exp(beta * q_stage1_mb)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta * q_stage2_mf[state_idx])
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        # Action value updating for choice 1
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        q_stage1_mf[1 - action_1[trial]] *= (1 - decay_rate)
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        # Action value updating for choice 2
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        
        # Decay for unchosen option in the current state
        q_stage2_mf[state_idx, 1 - action_2[trial]] *= (1 - decay_rate)
        
        # Decay for both options in the unvisited state
        other_state = 1 - state_idx
        q_stage2_mf[other_state, 0] *= (1 - decay_rate)
        q_stage2_mf[other_state, 1] *= (1 - decay_rate)

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```
