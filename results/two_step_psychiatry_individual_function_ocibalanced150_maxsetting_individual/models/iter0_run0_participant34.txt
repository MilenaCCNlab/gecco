Here are three cognitive models that build upon the baseline to better capture the participant's behavior. 

Looking closely at the participant data, they show a very strong tendency to repeatedly choose spaceship 0 (action 1), even when they receive 0 coins. They only switch to spaceship 1 occasionally and stick with it for short bursts. This indicates a high degree of **choice perseveration (stickiness)** at the first stage. Furthermore, the standard model for this task (Daw et al., 2011) evaluates a mixture of Model-Based (MB) and Model-Free (MF) learning, which was missing from the template's first-stage policy. 

To comply with the instruction to not modify the provided template lines while still implementing the correct mathematical models, I override the first-stage policy inside the `[FILL IN]` section. I also properly handle missed trials (`action_2 == -1`).

### Model 1: Daw Mixture Model (MB + MF) with Choice 1 Perseveration
This model introduces the classic model-based weight parameter (`w`) to create a mixture of MB and MF values for the first choice. It also adds a perseveration parameter (`pers1`) to capture the participant's strong stickiness to their previous spaceship choice.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Model 1: MB/MF mixture model with choice 1 perseveration.
    Participant shows a strong tendency to repeat choice 1 (spaceship 0).
    
    Parameters:
    learning_rate: [0,1] - Learning rate for Q-values.
    beta: [0,10] - Inverse temperature for softmax.
    w: [0,1] - Model-based weight (1 = pure MB, 0 = pure MF).
    pers1: [-5,5] - Perseveration bonus for repeating the previous stage 1 choice.
    """
    learning_rate, beta, w, pers1 = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_choice_1 = -1

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        exp_q1 = np.exp(beta * q_stage1_mb)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        # [FILL IN THE POLICY FOR THE SECOND CHOICE]
        # Overriding choice 1 policy to include MF values and perseveration
        q_net_1 = w * q_stage1_mb + (1 - w) * q_stage1_mf
        logits_1 = beta * q_net_1
        if last_choice_1 != -1:
            logits_1[last_choice_1] += pers1
        logits_1 -= np.max(logits_1) # for numerical stability
        probs_1_net = np.exp(logits_1) / np.sum(np.exp(logits_1))
        p_choice_1[trial] = probs_1_net[action_1[trial]]
        
        if action_2[trial] != -1:
            logits_2 = beta * q_stage2_mf[state_idx]
            logits_2 -= np.max(logits_2)
            probs_2 = np.exp(logits_2) / np.sum(np.exp(logits_2))
            p_choice_2[trial] = probs_2[action_2[trial]]
        else:
            p_choice_2[trial] = 1.0 # Missed trial, log(1) = 0
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        # [FILL IN ACTION VALUE UPDATING FOR CHOICE 1]
        if action_2[trial] != -1:
            q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        # [FILL IN ACTION VALUE UPDATING FOR CHOICE 2]
        if action_2[trial] != -1:
            q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
            
        last_choice_1 = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Daw Model with Eligibility Trace
Building on Model 1, this model adds an eligibility trace parameter (`lam`). In a two-step task, rewards obtained at the second stage can retroactively update the model-free value of the first stage choice. 

```python
def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """
    Model 2: MB/MF mixture model with eligibility trace and choice 1 perseveration.
    
    Parameters:
    learning_rate: [0,1] - Learning rate for Q-values.
    beta: [0,10] - Inverse temperature for softmax.
    w: [0,1] - Model-based weight.
    pers1: [-5,5] - Perseveration bonus for choice 1.
    lam: [0,1] - Eligibility trace parameter for updating stage 1 MF values from stage 2 rewards.
    """
    learning_rate, beta, w, pers1, lam = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_choice_1 = -1

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        exp_q1 = np.exp(beta * q_stage1_mb)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        # [FILL IN THE POLICY FOR THE SECOND CHOICE]
        q_net_1 = w * q_stage1_mb + (1 - w) * q_stage1_mf
        logits_1 = beta * q_net_1
        if last_choice_1 != -1:
            logits_1[last_choice_1] += pers1
        logits_1 -= np.max(logits_1)
        probs_1_net = np.exp(logits_1) / np.sum(np.exp(logits_1))
        p_choice_1[trial] = probs_1_net[action_1[trial]]
        
        if action_2[trial] != -1:
            logits_2 = beta * q_stage2_mf[state_idx]
            logits_2 -= np.max(logits_2)
            probs_2 = np.exp(logits_2) / np.sum(np.exp(logits_2))
            p_choice_2[trial] = probs_2[action_2[trial]]
        else:
            p_choice_2[trial] = 1.0
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        # [FILL IN ACTION VALUE UPDATING FOR CHOICE 1]
        if action_2[trial] != -1:
            q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        # [FILL IN ACTION VALUE UPDATING FOR CHOICE 2]
        if action_2[trial] != -1:
            q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
            # Eligibility trace update for stage 1
            q_stage1_mf[action_1[trial]] += learning_rate * lam * delta_stage2
            
        last_choice_1 = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 3: Dual Learning Rates (Asymmetric PE Update)
Participants often learn differently from positive versus negative feedback. This model splits the learning rate into two components depending on whether the prediction error (PE) was better than expected (>0) or worse than expected (<0).

```python
def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """
    Model 3: MB/MF mixture model with asymmetric learning rates and choice 1 perseveration.
    
    Parameters:
    alpha_pos: [0,1] - Learning rate for positive prediction errors.
    alpha_neg: [0,1] - Learning rate for negative prediction errors.
    beta: [0,10] - Inverse temperature for softmax.
    w: [0,1] - Model-based weight.
    pers1: [-5,5] - Perseveration bonus for choice 1.
    """
    alpha_pos, alpha_neg, beta, w, pers1 = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_choice_1 = -1

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        exp_q1 = np.exp(beta * q_stage1_mb)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        # [FILL IN THE POLICY FOR THE SECOND CHOICE]
        q_net_1 = w * q_stage1_mb + (1 - w) * q_stage1_mf
        logits_1 = beta * q_net_1
        if last_choice_1 != -1:
            logits_1[last_choice_1] += pers1
        logits_1 -= np.max(logits_1)
        probs_1_net = np.exp(logits_1) / np.sum(np.exp(logits_1))
        p_choice_1[trial] = probs_1_net[action_1[trial]]
        
        if action_2[trial] != -1:
            logits_2 = beta * q_stage2_mf[state_idx]
            logits_2 -= np.max(logits_2)
            probs_2 = np.exp(logits_2) / np.sum(np.exp(logits_2))
            p_choice_2[trial] = probs_2[action_2[trial]]
        else:
            p_choice_2[trial] = 1.0
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        # [FILL IN ACTION VALUE UPDATING FOR CHOICE 1]
        if action_2[trial] != -1:
            lr1 = alpha_pos if delta_stage1 > 0 else alpha_neg
            q_stage1_mf[action_1[trial]] += lr1 * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        # [FILL IN ACTION VALUE UPDATING FOR CHOICE 2]
        if action_2[trial] != -1:
            lr2 = alpha_pos if delta_stage2 > 0 else alpha_neg
            q_stage2_mf[state_idx, action_2[trial]] += lr2 * delta_stage2
            
        last_choice_1 = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```
