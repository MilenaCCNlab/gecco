Here are 3 new cognitive models to explain the participant's behavior, with unique parameter combinations and mechanisms (such as separate decay rates, outcome-dependent perseveration, and decoupled model-based/model-free inverse temperatures) to better capture the strong perseverative patterns and learning dynamics observed in the data.

### Model 1: Outcome-Dependent Perseveration with Decay
This model modifies the perseveration mechanism by distinguishing between trials where the previous choice was rewarded (`p_win`) versus unrewarded (`p_lose`). This directly addresses the participant's tendency to stick to the same spaceship, but allows the stickiness to be modulated by the outcome.

```python
import numpy as np

def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Model with decay for unchosen options and separate stage 1 perseveration 
    depending on whether the previous trial was rewarded (p_win) or not (p_lose).
    
    Parameters:
    alpha: learning rate [0, 1]
    decay: decay rate for unchosen Q-values [0, 1]
    beta_1: inverse temperature for stage 1 [0, 10]
    beta_2: inverse temperature for stage 2 [0, 10]
    w: weight of model-based vs model-free [0, 1]
    lam: eligibility trace [0, 1]
    p_win: choice perseveration for stage 1 after a rewarded trial [0, 10]
    p_lose: choice perseveration for stage 1 after an unrewarded trial [0, 10]
    """
    alpha, decay, beta_1, beta_2, w, lam, p_win, p_lose = model_parameters
    n_trials = len(action_1)
    
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action_1 = -1
    last_reward = 0
    
    for trial in range(n_trials):
        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        rep_1 = np.zeros(2)
        if last_action_1 != -1:
            rep_1[last_action_1] = 1
            
        pers_weight = p_win if last_reward == 1 else p_lose
        
        logits_1 = beta_1 * q_stage1_net + pers_weight * rep_1
        logits_1 -= np.max(logits_1)
        exp_q1 = np.exp(logits_1)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]
        
        # policy for the second choice
        logits_2 = beta_2 * q_stage2_mf[state_idx]
        logits_2 -= np.max(logits_2)
        exp_q2 = np.exp(logits_2)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
        
        # Decay for unchosen options
        unchosen_1 = 1 - action_1[trial]
        q_stage1_mf[unchosen_1] *= (1 - decay)
        for s in range(2):
            for a in range(2):
                if not (s == state_idx and a == action_2[trial]):
                    q_stage2_mf[s, a] *= (1 - decay)
                    
        # Action value updating
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += alpha * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += alpha * delta_stage2
        q_stage1_mf[action_1[trial]] += alpha * lam * delta_stage2
        
        last_action_1 = action_1[trial]
        last_reward = reward[trial]
        
    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Stage-Specific Decay Rates
This model introduces separate decay rates for stage 1 vs. stage 2 Q-values. Because there are four distinct aliens in stage 2 and only two spaceships in stage 1, unvisited states/actions might decay at different speeds for each stage.

```python
import numpy as np

def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """
    Model with separate decay rates for stage 1 and stage 2 unchosen options,
    along with strong stage 1 choice perseveration.
    
    Parameters:
    alpha: learning rate [0, 1]
    decay_1: decay rate for unchosen Q-values in stage 1 [0, 1]
    decay_2: decay rate for unchosen Q-values in stage 2 [0, 1]
    beta_1: inverse temperature for stage 1 [0, 10]
    beta_2: inverse temperature for stage 2 [0, 10]
    w: weight of model-based vs model-free [0, 1]
    lam: eligibility trace [0, 1]
    p_1: choice perseveration for stage 1 [0, 10]

    p_choice_2 = np.zeros(n_trials)

        q_stage1_mf[action_1[trial]] += alpha * lam * delta_stage2
```

### Model 3: Decoupled MB/MF Inverse Temperatures
Instead of a single `beta_1` scaled by a weighting parameter `w`, this model leverages completely decoupled inverse temperatures for the model-based (`beta_mb`) and model-free (`beta_mf`) signals. This permits differential exploitation magnitudes for the two learning strategies.

```python
import numpy as np

def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """
    Model that separates the inverse temperature for model-based (beta_mb) 
    and model-free (beta_mf) values at stage 1, replacing the weighting parameter w.
    Includes decay and perseveration for both stages.
    
    Parameters:
    alpha: learning rate [0, 1]
    decay: decay rate for unchosen Q-values [0, 1]
    beta_mb: inverse temperature for model-based Q-values at stage 1 [0, 10]
    beta_mf: inverse temperature for model-free Q-values at stage 1 [0, 10]
    beta_2: inverse temperature for stage 2 [0, 10]
    lam: eligibility trace [0, 1]
    p_1: choice perseveration for stage 1 [0, 10]
    p_2: choice perseveration for stage 2 [0, 10]
    """
    alpha, decay, beta_mb, beta_mf, beta_2, lam, p_1, p_2 = model_parameters
    n_trials = len(action_1)
    
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action_1 = -1
    last_action_2 = -1
    last_state = -1
    
    for trial in range(n_trials):
        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        rep_1 = np.zeros(2)
        if last_action_1 != -1:
            rep_1[last_action_1] = 1
            
        logits_1 = beta_mb * q_stage1_mb + beta_mf * q_stage1_mf + p_1 * rep_1
        logits_1 -= np.max(logits_1)
        exp_q1 = np.exp(logits_1)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]
        
        # policy for the second choice
        rep_2 = np.zeros(2)
        if last_state == state_idx and last_action_2 != -1:
            rep_2[last_action_2] = 1
            
        logits_2 = beta_2 * q_stage2_mf[state_idx] + p_2 * rep_2
        logits_2 -= np.max(logits_2)
        exp_q2 = np.exp(logits_2)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
        
        # Decay for unchosen options
        unchosen_1 = 1 - action_1[trial]
        q_stage1_mf[unchosen_1] *= (1 - decay)
        for s in range(2):
            for a in range(2):
                if not (s == state_idx and a == action_2[trial]):
                    q_stage2_mf[s, a] *= (1 - decay)
                    
        # Action value updating
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += alpha * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += alpha * delta_stage2
        q_stage1_mf[action_1[trial]] += alpha * lam * delta_stage2
        
        last_action_1 = action_1[trial]
        last_action_2 = action_2[trial]
        last_state = state_idx
        
    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```
