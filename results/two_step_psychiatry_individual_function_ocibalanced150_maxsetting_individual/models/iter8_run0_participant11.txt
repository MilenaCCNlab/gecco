Here are 3 new cognitive models that build upon the best model so far. Given the near-perfect correlation between the stage 1 and stage 2 choices (i.e., `action_1` is almost always identical to `action_2`), the `chunking_bias` parameter is crucial. Furthermore, the presence of long streaks of identical choices suggests strong perseveration and decay mechanisms. These new models introduce additional well-established reinforcement learning mechanisms (eligibility traces, asymmetric learning rates, and separate inverse temperatures) to better capture the learning dynamics.

### Model 1: Eligibility Trace Model
This model introduces an eligibility trace (`lam`) to the best-performing model. The eligibility trace allows the reward prediction error from the second stage to directly update the model-free value of the first-stage action, which can speed up learning of multi-step dependencies.

```python
import numpy as np

def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Model with decay, eligibility trace (lambda), stage 1 perseveration, and motor chunking bias.
    
    Parameters:
    alpha: learning rate [0, 1]
    decay: decay rate for unchosen actions [0, 1]
    beta: inverse temperature [0, 10]
    w: model-based weight [0, 1]
    lam: eligibility trace [0, 1]
    pers_1: choice perseveration for stage 1 [-5, 5]
    chunking_bias: bias to choose the same motor action in stage 2 as in stage 1 [-5, 5]
    """
    alpha, decay, beta, w, lam, pers_1, chunking_bias = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action_1 = -1

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        logits_1 = beta * np.copy(q_net)
        if last_action_1 != -1:
            logits_1[last_action_1] += pers_1
            
        logits_1 -= np.max(logits_1)
        exp_q1 = np.exp(logits_1)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]

        # policy for the second choice
        logits_2 = beta * np.copy(q_stage2_mf[state_idx])
        logits_2[action_1[trial]] += chunking_bias
            
        logits_2 -= np.max(logits_2)
        exp_q2 = np.exp(logits_2)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # Action value updating
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += alpha * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += alpha * delta_stage2
        
        # Eligibility trace update for stage 1
        q_stage1_mf[action_1[trial]] += alpha * lam * delta_stage2

        # Decay for unchosen actions
        unchosen_1 = 1 - action_1[trial]
        q_stage1_mf[unchosen_1] *= (1 - decay)
        
        unchosen_2 = 1 - action_2[trial]
        q_stage2_mf[state_idx, unchosen_2] *= (1 - decay)
        
        unvisited_state = 1 - state_idx
        q_stage2_mf[unvisited_state, 0] *= (1 - decay)
        q_stage2_mf[unvisited_state, 1] *= (1 - decay)

        last_action_1 = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Asymmetric Learning Rates Model
Participants often learn differently from positive and negative feedback. This model introduces separate learning rates (`alpha_pos` and `alpha_neg`) for positive and negative prediction errors, while retaining the core features of the best model.

```python
import numpy as np

def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """
    Model with dual learning rates (positive/negative PEs), decay, stage 1 perseveration, and chunking bias.
    
    Parameters:
    alpha_pos: learning rate for positive PEs [0, 1]
    alpha_neg: learning rate for negative PEs [0, 1]
    decay: decay rate for unchosen actions [0, 1]
    beta: inverse temperature [0, 10]
    w: model-based weight [0, 1]
    pers_1: choice perseveration for stage 1 [-5, 5]
    chunking_bias: bias to choose the same motor action in stage 2 as in stage 1 [-5, 5]
    """
    alpha_pos, alpha_neg, decay, beta, w, pers_1, chunking_bias = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action_1 = -1

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        logits_1 = beta * np.copy(q_net)
        if last_action_1 != -1:
            logits_1[last_action_1] += pers_1
            
        logits_1 -= np.max(logits_1)
        exp_q1 = np.exp(logits_1)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]

        # policy for the second choice
        logits_2 = beta * np.copy(q_stage2_mf[state_idx])
        logits_2[action_1[trial]] += chunking_bias
            
        logits_2 -= np.max(logits_2)
        exp_q2 = np.exp(logits_2)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # Action value updating with asymmetric learning rates
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        alpha_1 = alpha_pos if delta_stage1 > 0 else alpha_neg
        q_stage1_mf[action_1[trial]] += alpha_1 * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        alpha_2 = alpha_pos if delta_stage2 > 0 else alpha_neg
        q_stage2_mf[state_idx, action_2[trial]] += alpha_2 * delta_stage2

        # Decay for unchosen actions
        unchosen_1 = 1 - action_1[trial]
        q_stage1_mf[unchosen_1] *= (1 - decay)
        
        unchosen_2 = 1 - action_2[trial]
        q_stage2_mf[state_idx, unchosen_2] *= (1 - decay)
        
        unvisited_state = 1 - state_idx
        q_stage2_mf[unvisited_state, 0] *= (1 - decay)
        q_stage2_mf[unvisited_state, 1] *= (1 - decay)

        last_action_1 = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 3: Dual Inverse Temperature Model
Exploration/exploitation trade-offs often differ between the two stages in this task. This model introduces separate inverse temperatures (`beta_1` and `beta_2`) for stage 1 and stage 2 to account for potential differences in choice stochasticity between the stages.

```python
import numpy as np

def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """
    Model with decay, separate temperatures for stage 1 and 2, stage 1 perseveration, and chunking bias.
    
    Parameters:
    alpha: learning rate [0, 1]
    decay: decay rate for unchosen actions [0, 1]
    beta_1: inverse temperature for stage 1 [0, 10]
    beta_2: inverse temperature for stage 2 [0, 10]
    w: model-based weight [0, 1]
    pers_1: choice perseveration for stage 1 [-5, 5]
    chunking_bias: bias to choose the same motor action in stage 2 as in stage 1 [-5, 5]

    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action_1 = -1

    for trial in range(n_trials):

        # policy for the first choice
```
