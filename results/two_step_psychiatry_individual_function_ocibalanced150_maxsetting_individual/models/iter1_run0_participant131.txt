### Model 1: Asymmetric Learning Rates
Humans often exhibit an optimism or pessimism bias, learning at different speeds depending on whether the outcome was better or worse than expected. This model separates the learning rate into two parameters based on the sign of the prediction error.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """Model 1: Asymmetric Learning Rates (Positive and Negative PE).
    
    This model assumes that participants learn differently from positive and 
    negative feedback. It uses separate learning rates for positive (better than 
    expected) and negative (worse than expected) prediction errors.
    
    Parameters:
    alpha_pos: [0, 1] - Learning rate for positive prediction errors (PE > 0).
    alpha_neg: [0, 1] - Learning rate for negative prediction errors (PE <= 0).
    beta: [0, 10] - Inverse temperature for softmax action selection.
    """
    alpha_pos, alpha_neg, beta = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        exp_q1 = np.exp(beta * q_stage1_mb)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta * q_stage2_mf[state_idx])
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        lr_stage1 = alpha_pos if delta_stage1 > 0 else alpha_neg
        q_stage1_mf[action_1[trial]] += lr_stage1 * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        lr_stage2 = alpha_pos if delta_stage2 > 0 else alpha_neg
        q_stage2_mf[state_idx, action_2[trial]] += lr_stage2 * delta_stage2
        
    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Counterfactual Updating
In tasks with binary options and binary rewards, participants often display a "fictitious play" or counterfactual reasoning bias. If they ask an alien for gold and get nothing, they might assume the *other* alien on that planet would have given them a coin, and they update its value in the opposite direction.

```python
def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """Model 2: Counterfactual Updating at Stage 2.
    
    This model assumes that participants update not only the chosen alien but also 
    the unchosen alien on the visited planet. Given the binary nature of rewards, 
    they might infer that if the chosen alien yielded a reward, the other would 
    not, and vice versa.
    
    Parameters:
    learning_rate: [0, 1] - Learning rate for the chosen action.
    counterfactual_rate: [0, 1] - Learning rate for the unchosen action on the same planet.
    beta: [0, 10] - Inverse temperature for softmax action selection.
    """
    learning_rate, counterfactual_rate, beta = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        exp_q1 = np.exp(beta * q_stage1_mb)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta * q_stage2_mf[state_idx])
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        
        # Counterfactual update for the unchosen action on the arrived planet
        unchosen_action = 1 - action_2[trial]
        counterfactual_reward = 1 - reward[trial]
        delta_cf = counterfactual_reward - q_stage2_mf[state_idx, unchosen_action]
        q_stage2_mf[state_idx, unchosen_action] += counterfactual_rate * delta_cf
        
    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 3: Dynamic Transition Matrix Learning
While the template assumes a fixed `[0.7, 0.3]` transition matrix, participants often don't trust the instructions entirely and continuously update their internal map of the environment. This model introduces a parameter allowing the participant to dynamically learn the transition probabilities from their experienced flights.

```python
def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """Model 3: Dynamic Transition Matrix Learning.
    
    This model assumes that the participant dynamically updates their internal 
    model of the transition probabilities between spaceships and planets based on 
    their flight experience, rather than keeping it strictly fixed at 70/30.
    
    Parameters:
    learning_rate: [0, 1] - Learning rate for Q-value updates.
    alpha_trans: [0, 1] - Learning rate for updating the transition matrix probabilities.
    beta: [0, 10] - Inverse temperature for softmax action selection.
    """
    learning_rate, alpha_trans, beta = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        exp_q1 = np.exp(beta * q_stage1_mb)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta * q_stage2_mf[state_idx])
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        
        # Update internal transition matrix based on observed transition
        transition_matrix[action_1[trial], state_idx] += alpha_trans * (1.0 - transition_matrix[action_1[trial], state_idx])
        transition_matrix[action_1[trial], 1 - state_idx] += alpha_trans * (0.0 - transition_matrix[action_1[trial], 1 - state_idx])
        
    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```
