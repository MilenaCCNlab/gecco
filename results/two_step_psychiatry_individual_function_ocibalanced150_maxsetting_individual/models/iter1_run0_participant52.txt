Here are 3 new cognitive models that extend the standard two-step model to test different psychological mechanisms, while avoiding the parameter combinations you have already explored.

### Model 1: Choice Stickiness (Perseveration)
Participants often exhibit a tendency to repeat their previous first-stage choice regardless of the outcome (perseveration). This model adds a `st` (stickiness) parameter which provides a bonus to the Q-value of the stage-1 action if it was chosen in the previous trial.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Two-step model with choice stickiness (perseveration) at stage 1.
    Bounds:
    alpha: [0,1] - learning rate
    beta: [0,10] - inverse temperature
    w: [0,1] - model-based weight
    lam: [0,1] - eligibility trace parameter
    st: [-5,5] - stickiness parameter for previous stage 1 choice
    """
    import numpy as np
    alpha, beta, w, lam, st = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action_1 = -1

    for trial in range(n_trials):
        if action_1[trial] == -1:
            p_choice_1[trial] = 1.0
            p_choice_2[trial] = 1.0
            continue

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        stickiness_bonus = np.zeros(2)
        if last_action_1 != -1:
            stickiness_bonus[last_action_1] = st
            
        exp_q1 = np.exp(beta * (q_net + stickiness_bonus - np.max(q_net + stickiness_bonus)))
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta * (q_stage2_mf[state_idx] - np.max(q_stage2_mf[state_idx])))
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        
        # Action value updating for choice 1
        q_stage1_mf[action_1[trial]] += alpha * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        
        # Action value updating for choice 2
        q_stage2_mf[state_idx, action_2[trial]] += alpha * delta_stage2
        q_stage1_mf[action_1[trial]] += alpha * lam * delta_stage2
        
        last_action_1 = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Stage-Specific Inverse Temperatures
Participants might be more exploratory in one stage and more deterministic in another. This model separates the softmax inverse temperature into `beta1` (for stage 1) and `beta2` (for stage 2), allowing for different levels of choice stochasticity depending on the decision stage.

```python
def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """
    Two-step model with separate inverse temperatures for stage 1 and stage 2.
    Bounds:
    alpha: [0,1] - learning rate
    beta1: [0,10] - inverse temperature for stage 1
    beta2: [0,10] - inverse temperature for stage 2
    w: [0,1] - model-based weight
    lam: [0,1] - eligibility trace parameter
    """
    import numpy as np
    alpha, beta1, beta2, w, lam = model_parameters
    n_trials = len(action_1)

    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))

    for trial in range(n_trials):
        if action_1[trial] == -1:
            p_choice_1[trial] = 1.0
            p_choice_2[trial] = 1.0
            continue

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_net = w * q_stage1_mb + (1 - w) * q_stage1_mf

        # Action value updating for choice 1
        q_stage1_mf[action_1[trial]] += alpha * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]

    return log_loss
```

### Model 3: Stage-Specific Learning Rates
Often, the speed at which participants update their values differs across the abstract choice (which spaceship to take) versus the concrete choice (which alien to ask). This model tests this hypothesis by splitting the learning rate into `alpha1` (for stage 1) and `alpha2` (for stage 2).
