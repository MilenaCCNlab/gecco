Here are 3 new cognitive models that systematically build upon the best model so far. The participant data reveals an overwhelmingly strong preference for choosing spaceship 0 in Stage 1 (Action 0 is chosen in 188 out of 200 trials). The best model successfully captured this using a `bias_action0` parameter but used 8 parameters. These new models explore whether we can achieve an equally good or better fit (penalized for complexity via AIC/BIC) by simplifying the model—specifically by removing the decay rate, merging the two temperature parameters (`beta`) into one, or both. 

### Model 1
Simplifies the best model by removing the `decay_rate` parameter (reducing from 8 to 7 parameters). It assumes that unchosen Stage 2 actions do not decay, which might prevent overfitting while retaining the crucial `bias_action0`, `stickiness`, and `lam` parameters.

```python
import numpy as np

def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Model 1: 7 parameters. Simplifies the best model by removing the decay rate, 
    but retains the critical bias for Action 0, stage-specific betas, stickiness, 
    eligibility trace (lam), and model-based weight (w).
    
    Parameters:
    learning_rate: [0,1] - Learning rate for updating action values.
    beta_stage1: [0,10] - Inverse temperature for Stage 1 choices.
    beta_stage2: [0,10] - Inverse temperature for Stage 2 choices.
    w: [0,1] - Weighting between model-based (1) and model-free (0) systems.
    stickiness: [0,10] - Choice perseveration bonus for Stage 1.
    lam: [0,1] - Eligibility trace for Stage 2 reward updating Stage 1 value.
    bias_action0: [0,10] - Intrinsic bias/bonus for choosing Action 0 in Stage 1.
    """
    learning_rate, beta_stage1, beta_stage2, w, stickiness, lam, bias_action0 = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action = -1

    for trial in range(n_trials):
        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        logits_1 = beta_stage1 * q_stage1_net
        if last_action != -1:
            logits_1[last_action] += stickiness
        logits_1[0] += bias_action0
            
        exp_q1 = np.exp(logits_1 - np.max(logits_1))
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]

        # policy for the second choice
        logits_2 = beta_stage2 * q_stage2_mf[state_idx]
        exp_q2 = np.exp(logits_2 - np.max(logits_2))
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        # Action value updating for choice 1
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        # Action value updating for choice 2
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        
        # Eligibility trace
        q_stage1_mf[action_1[trial]] += learning_rate * lam * delta_stage2
        
        last_action = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2
Further simplifies the model down to 6 parameters. It merges `beta_stage1` and `beta_stage2` into a single `beta` parameter for both stages. Because the participant's Stage 1 choices are heavily dominated by the `bias_action0` and `stickiness`, a separate temperature parameter for Stage 1 might be redundant.

```python
import numpy as np

def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """
    Model 2: 6 parameters. Uses a single beta for both stages to improve parsimony 
    and removes decay rate, while retaining the critical bias for Action 0, stickiness, 
    eligibility trace, and model-based weight (w).
    
    Parameters:
    learning_rate: [0,1] - Learning rate for updating action values.
    beta: [0,10] - Inverse temperature for both Stage 1 and Stage 2 choices.
    w: [0,1] - Weighting between model-based (1) and model-free (0) systems.
    stickiness: [0,10] - Choice perseveration bonus for Stage 1.
    lam: [0,1] - Eligibility trace for Stage 2 reward updating Stage 1 value.
    bias_action0: [0,10] - Intrinsic bias/bonus for choosing Action 0 in Stage 1.
    """

    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
```

### Model 3
This model keeps the `decay_rate` parameter from the best model (which helps model drifting probabilities in the task design) but uses a single `beta` parameter for both stages (7 parameters). This tests whether the separation of temperatures was the unnecessary complexity in the 8-parameter model.

```python
import numpy as np

def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """
    Model 3: 7 parameters. Similar to the best model but uses a single beta for both 
    stages to reduce overfitting, while keeping decay_rate, stickiness, lam, and bias_action0.
    
    Parameters:
    learning_rate: [0,1] - Learning rate for updating action values.
    decay_rate: [0,1] - Rate at which unchosen Stage 2 actions decay toward 0.5.
    beta: [0,10] - Inverse temperature for both Stage 1 and Stage 2 choices.
    w: [0,1] - Weighting between model-based (1) and model-free (0) systems.
    stickiness: [0,10] - Choice perseveration bonus for Stage 1.
    lam: [0,1] - Eligibility trace for Stage 2 reward updating Stage 1 value.
    bias_action0: [0,10] - Intrinsic bias/bonus for choosing Action 0 in Stage 1.
    """
    learning_rate, decay_rate, beta, w, stickiness, lam, bias_action0 = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action = -1

    for trial in range(n_trials):
        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        logits_1 = beta * q_stage1_net
        if last_action != -1:
            logits_1[last_action] += stickiness
        logits_1[0] += bias_action0
            
        exp_q1 = np.exp(logits_1 - np.max(logits_1))
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]

        # policy for the second choice
        logits_2 = beta * q_stage2_mf[state_idx]
        exp_q2 = np.exp(logits_2 - np.max(logits_2))
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        # Action value updating for choice 1
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        # Action value updating for choice 2
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        
        # Apply decay to unchosen options and update chosen option
        for s in range(2):
            for a in range(2):
                if s == state_idx and a == action_2[trial]:
                    q_stage2_mf[s, a] += learning_rate * delta_stage2
                else:
                    q_stage2_mf[s, a] += decay_rate * (0.5 - q_stage2_mf[s, a])
        
        # Eligibility trace
        q_stage1_mf[action_1[trial]] += learning_rate * lam * delta_stage2
        
        last_action = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```
