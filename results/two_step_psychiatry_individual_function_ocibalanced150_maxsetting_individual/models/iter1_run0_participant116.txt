Here are 3 new cognitive models that explore alternative mechanisms for decision-making in the two-step task. Each model builds upon the classic Daw (2011) hybrid model but introduces unique parameterizations to capture nuanced participant behaviors.

### Model 1: Separate Learning Rates for Stage 1 and Stage 2
Participants often exhibit different learning dynamics for the first stage (which involves transition probabilities and abstract credit assignment) compared to the second stage (which is a direct reward learning scenario). This model separates the learning rate into `lr_stage1` and `lr_stage2`.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Model 1: Separate Learning Rates for Stage 1 and Stage 2
    Uses different learning rates for the first and second stage updates to account for 
    potential differences in learning abstract transitions vs. direct reward contingencies.
    
    Bounds:
    lr_stage1: [0,1] - Learning rate for Stage 1 Q-values
    lr_stage2: [0,1] - Learning rate for Stage 2 Q-values
    beta: [0,10] - Inverse temperature for softmax action selection
    w: [0,1] - Model-based weight
    lam: [0,1] - Eligibility trace parameter
    st: [-5,5] - Choice stickiness (perseveration)
    """
    lr_stage1, lr_stage2, beta, w, lam, st = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action = -1

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        stickiness = np.zeros(2)
        if last_action != -1:
            stickiness[last_action] = 1.0
            
        exp_q1 = np.exp(beta * q_net + st * stickiness)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta * q_stage2_mf[state_idx])
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        # ACTION VALUE UPDATING
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += lr_stage1 * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += lr_stage2 * delta_stage2
        
        # Eligibility trace update applied to stage 1 using stage 1's learning rate
        q_stage1_mf[action_1[trial]] += lr_stage1 * lam * delta_stage2
        
        last_action = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Separate Inverse Temperatures for Stage 1 and Stage 2
It is highly common for choice stochasticity to differ between the two stages. For example, a participant might be very exploratory (or noisy) in their spaceship choices but highly exploitative when choosing aliens. This model uses `beta1` for stage 1 and `beta2` for stage 2.

```python
def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """
    Model 2: Separate Inverse Temperatures for Stage 1 and Stage 2
    Uses different softmax inverse temperatures for stage 1 and stage 2 choices to 
    allow for varying levels of exploratory/exploitative behavior between the stages.
    
    Bounds:
    learning_rate: [0,1] - Learning rate for Q-value updates
    beta1: [0,10] - Inverse temperature for Stage 1
    beta2: [0,10] - Inverse temperature for Stage 2
    w: [0,1] - Model-based weight
    lam: [0,1] - Eligibility trace parameter
    st: [-5,5] - Choice stickiness for Stage 1
    """
    learning_rate, beta1, beta2, w, lam, st = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action = -1

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2

        # policy for the second choice

        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1

        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2

    return log_loss
```

### Model 3: Reward-dependent Stickiness (Win-Stay / Lose-Shift)
Instead of a single perseveration parameter, this model breaks stickiness into two distinct elements dependent on the outcome of the previous trial. This captures the heuristic "win-stay/lose-shift" behavior pattern that often runs in parallel with reinforcement learning. 

```python
def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """
    Model 3: Reward-dependent Stickiness (Win-Stay / Lose-Shift)
    Incorporates separate stickiness parameters for when the previous trial was 
    rewarded vs unrewarded to capture heuristic win-stay/lose-shift behavior.
    
    Bounds:
    learning_rate: [0,1] - Learning rate for Q-value updates
    beta: [0,10] - Inverse temperature for softmax action selection
    w: [0,1] - Model-based weight
    lam: [0,1] - Eligibility trace parameter
    st_win: [-5,5] - Choice stickiness if previous trial was rewarded
    st_lose: [-5,5] - Choice stickiness if previous trial was unrewarded
    """
    learning_rate, beta, w, lam, st_win, st_lose = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action = -1
    last_reward = -1

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        stickiness = np.zeros(2)
        if last_action != -1:
            if last_reward == 1:
                stickiness[last_action] = st_win
            else:
                stickiness[last_action] = st_lose
            
        exp_q1 = np.exp(beta * q_net + stickiness)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta * q_stage2_mf[state_idx])
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        # ACTION VALUE UPDATING
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        q_stage1_mf[action_1[trial]] += learning_rate * lam * delta_stage2
        
        last_action = action_1[trial]
        last_reward = reward[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```
