Here are 3 new cognitive models that explore alternative mechanisms for the participant's behavior. Given the participant's strong preference for Action 0 (spaceship 0) and a potential preference for Alien 0 in Stage 2, these models introduce a Stage 2 bias (`bias_alien0`) and also test whether a purely model-free agent (removing the MB weight `w`) might be sufficient when combined with the other parameters.

### Model 1: Adding Stage 2 Bias (8 parameters)
This model builds on the best model so far by introducing an intrinsic bias for choosing Alien 0 in Stage 2 (`bias_alien0`). Since the participant frequently selects Alien 0, this parameter may capture a baseline preference independent of learned values.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Model 1: 8 parameters. Adds a Stage 2 bias for choosing alien 0 (bias_alien0) to the best model.
    
    Parameters:
    learning_rate: [0,1] - Learning rate for updating action values.
    decay_rate: [0,1] - Rate at which unchosen Stage 2 actions decay toward 0.5.
    beta: [0,10] - Inverse temperature for both Stage 1 and Stage 2 choices.
    w: [0,1] - Weighting between model-based (1) and model-free (0) systems.
    stickiness: [0,10] - Choice perseveration bonus for Stage 1.
    lam: [0,1] - Eligibility trace for Stage 2 reward updating Stage 1 value.
    bias_action0: [0,10] - Intrinsic bias/bonus for choosing Action 0 in Stage 1.
    bias_alien0: [0,10] - Intrinsic bias/bonus for choosing Alien 0 in Stage 2.
    """
    learning_rate, decay_rate, beta, w, stickiness, lam, bias_action0, bias_alien0 = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action = -1

    for trial in range(n_trials):
        # Stage 1 Policy
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        logits_1 = beta * q_stage1_net
        if last_action != -1:
            logits_1[last_action] += stickiness
        logits_1[0] += bias_action0
            
        exp_q1 = np.exp(logits_1 - np.max(logits_1))
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]

        # Stage 2 Policy
        logits_2 = beta * q_stage2_mf[state_idx]
        logits_2[0] += bias_alien0
        
        exp_q2 = np.exp(logits_2 - np.max(logits_2))
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # Value Updates
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1

        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]

        for s in range(2):
            for a in range(2):
                if s == state_idx and a == action_2[trial]:
                    q_stage2_mf[s, a] += learning_rate * delta_stage2
                else:
                    q_stage2_mf[s, a] += decay_rate * (0.5 - q_stage2_mf[s, a])

        q_stage1_mf[action_1[trial]] += learning_rate * lam * delta_stage2
        
        last_action = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Stage 2 Bias without Decay (7 parameters)
This model removes `decay_rate` to test if the addition of `bias_alien0` makes the decay mechanism redundant, offering a more parsimonious 7-parameter configuration.

### Model 3: Purely Model-Free Agent with Decay and Bias (6 parameters)
Given the participant's extreme bias toward Action 0, it is possible they are not utilizing the model-based system at all. This model removes the `w` weighting parameter entirely, rendering the agent purely model-free, while keeping trace (`lam`), `decay_rate`, `stickiness`, and `bias_action0`.

```python
def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """
    Model 3: 6 parameters. Purely model-free agent (no w parameter) with decay, stickiness, 
    eligibility trace, and bias for action 0.
    
    Parameters:
    learning_rate: [0,1] - Learning rate for updating action values.
    decay_rate: [0,1] - Rate at which unchosen Stage 2 actions decay toward 0.5.
    beta: [0,10] - Inverse temperature for both Stage 1 and Stage 2 choices.
    stickiness: [0,10] - Choice perseveration bonus for Stage 1.
    lam: [0,1] - Eligibility trace for Stage 2 reward updating Stage 1 value.
    bias_action0: [0,10] - Intrinsic bias/bonus for choosing Action 0 in Stage 1.
    """
    learning_rate, decay_rate, beta, stickiness, lam, bias_action0 = model_parameters
    n_trials = len(action_1)
  
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action = -1

    for trial in range(n_trials):
        # Stage 1 Policy (Purely Model-Free)
        logits_1 = beta * q_stage1_mf.copy()
        if last_action != -1:
            logits_1[last_action] += stickiness
        logits_1[0] += bias_action0
            
        exp_q1 = np.exp(logits_1 - np.max(logits_1))
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]

        # Stage 2 Policy
        logits_2 = beta * q_stage2_mf[state_idx]
        exp_q2 = np.exp(logits_2 - np.max(logits_2))
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # Value Updates
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
```
