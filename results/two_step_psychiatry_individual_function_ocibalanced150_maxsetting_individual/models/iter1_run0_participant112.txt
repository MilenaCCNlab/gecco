Here are 3 new cognitive models that build upon the baseline by introducing mechanisms commonly used to explain behavior in the two-step task, such as model-based/model-free mixing, eligibility traces, separate learning rates, separate decision temperatures (betas), and choice stickiness. 

### Model 1: Full Daw et al. 2011 Model
This model incorporates the full set of mechanisms from the classic Daw et al. (2011) paper. It assumes a mixture of model-based and model-free control in the first stage (weighted by `w`), an eligibility trace (`lam`) that allows stage 2 rewards to directly update stage 1 model-free values, separate exploration rates (`beta_1`, `beta_2`) for each stage, and a choice `stickiness` parameter to capture the participant's tendency to perseverate on their previous stage 1 choice.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Model 1: Full Daw et al. 2011 Model
    Includes model-based and model-free weighting (w), eligibility trace (lam),
    separate betas for stage 1 and 2, and choice stickiness.
    
    Bounds:
    learning_rate: [0,1]
    beta_1: [0,10]
    beta_2: [0,10]
    w: [0,1]
    lam: [0,1]
    stickiness: [0,5]
    """
    learning_rate, beta_1, beta_2, w, lam, stickiness = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    last_action_1 = -1

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        if last_action_1 != -1:
            q_stage1_net[last_action_1] += stickiness
            
        exp_q1 = np.exp(beta_1 * q_stage1_net)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta_2 * q_stage2_mf[state_idx])
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        
        # Eligibility trace update for choice 1
        q_stage1_mf[action_1[trial]] += learning_rate * lam * delta_stage2
        
        last_action_1 = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Mixture Model with Separate Stage Learning Rates
This model drops the eligibility trace and stickiness to maintain parsimony but introduces separate learning rates (`lr_1`, `lr_2`) for stage 1 and stage 2. This is useful if the participant updates their values at different speeds depending on whether they are evaluating the spaceship (stage 1) or the alien (stage 2). It also includes the mixture weight `w` and separate `beta` parameters.

```python
def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """
    Model 2: Mixture of Model-Based and Model-Free with separate learning rates.
    Uses separate learning rates and separate betas for stage 1 and stage 2,
    and a weighting parameter (w) for stage 1 values.
    
    Bounds:
    lr_1: [0,1]
    lr_2: [0,1]
    beta_1: [0,10]
    beta_2: [0,10]
    w: [0,1]
    """
    lr_1, lr_2, beta_1, beta_2, w = model_parameters
    n_trials = len(action_1)

    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf

        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += lr_1 * delta_stage1

        q_stage2_mf[state_idx, action_2[trial]] += lr_2 * delta_stage2
```

### Model 3: Parsimonious Mixture Model with Choice Stickiness
This model provides a highly parsimonious alternative (only 4 parameters) by tying the learning rates and betas across both stages to a single `learning_rate` and `beta`. It evaluates whether a basic combination of model-based mixing (`w`) and simple perseveration (`stickiness`) is enough to explain the participant's sequence of choices without needing separate parameters for each stage.
