### Model 1: `learning_rate, beta_1, beta_2, w, lam, rho, decay`
This model builds on your best model by separating the inverse temperature (`beta`) for the two stages. Participants often exhibit different levels of exploration/exploitation in Stage 1 versus Stage 2. Allowing separate `beta` parameters can capture this difference while retaining the successful mechanisms like choice stickiness (`rho`) and value decay (`decay`) for unchosen options.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Model 1: Single learning rate, two betas (one for each stage), model-based weight, 
    eligibility trace, choice stickiness, and decay for unchosen options.
    
    Bounds:
    learning_rate: [0, 1]
    beta_1: [0, 10]
    beta_2: [0, 10]
    w: [0, 1]
    lam: [0, 1]
    rho: [0, 5]
    decay: [0, 1]
    """
    learning_rate, beta_1, beta_2, w, lam, rho, decay = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action_1 = -1
    last_action_2 = np.array([-1, -1])

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        stickiness_1 = np.zeros(2)
        if last_action_1 != -1:
            stickiness_1[last_action_1] = rho
            
        q1_vals = q_stage1_net + stickiness_1
        exp_q1 = np.exp(beta_1 * (q1_vals - np.max(q1_vals)))
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]
        
        # policy for the second choice
        stickiness_2 = np.zeros(2)
        if last_action_2[state_idx] != -1:
            stickiness_2[last_action_2[state_idx]] = rho
            
        q2_vals = q_stage2_mf[state_idx] + stickiness_2
        exp_q2 = np.exp(beta_2 * (q2_vals - np.max(q2_vals)))
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
        
        # action value updating
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        
        q_stage1_mf[action_1[trial]] += learning_rate * lam * delta_stage2

        # decay for unchosen options
        q_stage1_mf[1 - action_1[trial]] *= (1 - decay)
        q_stage2_mf[state_idx, 1 - action_2[trial]] *= (1 - decay)
        q_stage2_mf[1 - state_idx, 0] *= (1 - decay)
        q_stage2_mf[1 - state_idx, 1] *= (1 - decay)
        
        last_action_1 = action_1[trial]
        last_action_2[state_idx] = action_2[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: `learning_rate, beta, w, lam, rho_win, rho_lose, rho_2, decay`
This model incorporates a "Win-Stay / Lose-Shift" heuristic explicitly into the stickiness parameters for Stage 1. Participants often show varying degrees of perseveration depending on whether the previous trial was rewarded (`rho_win`) or unrewarded (`rho_lose`). Stage 2 gets its own standard stickiness (`rho_2`). 

```python

    """
    Model 2: Single learning rate, single beta, model-based weight, eligibility trace, 
    win-stay/lose-shift stickiness for stage 1, stickiness for stage 2, and decay for unchosen options.
    
    Bounds:
    learning_rate: [0, 1]
    beta: [0, 10]
    w: [0, 1]
    lam: [0, 1]
    rho_win: [-5, 5]
    rho_lose: [-5, 5]
    rho_2: [0, 5]
    decay: [0, 1]
    """
    learning_rate, beta, w, lam, rho_win, rho_lose, rho_2, decay = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])

        exp_q2 = np.exp(beta * (q2_vals - np.max(q2_vals)))

        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        
        q_stage1_mf[action_1[trial]] += learning_rate * lam * delta_stage2

        # decay for unchosen options
        q_stage1_mf[1 - action_1[trial]] *= (1 - decay)

        q_stage2_mf[1 - state_idx, 0] *= (1 - decay)
        q_stage2_mf[1 - state_idx, 1] *= (1 - decay)
        
        last_action_1 = action_1[trial]
        last_action_2[state_idx] = action_2[trial]
        last_reward = reward[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```
