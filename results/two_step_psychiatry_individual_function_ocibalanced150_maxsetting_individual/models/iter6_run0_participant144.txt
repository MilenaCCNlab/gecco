Here are 3 new cognitive models that build upon your best-performing model. Since the decay of unchosen options (forgetting) was a key component of the best model, all three new models incorporate `decay_rate` while introducing new theoretically grounded mechanisms (asymmetric learning, separate stage temperatures, and separate stage learning rates) to capture additional variance in participant behavior.

### Model 1: Asymmetric Learning Model with Decay and Stickiness
This model separates the learning rate into `lr_pos` (for positive reward prediction errors) and `lr_neg` (for negative reward prediction errors). It is common in psychiatry and cognitive science for individuals to learn differently from better-than-expected versus worse-than-expected outcomes. 

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Asymmetric Learning Model with Decay and Stickiness.
    
    Parameters:
    lr_pos: [0, 1] - Learning rate for positive prediction errors (delta > 0).
    lr_neg: [0, 1] - Learning rate for negative prediction errors (delta <= 0).
    decay_rate: [0, 1] - Rate at which unchosen Q-values decay towards 0.5.
    beta: [0, 10] - Inverse temperature for choice probabilities.
    w: [0, 1] - Weighting between model-based (1) and model-free (0) Stage 1 values.
    eligibility: [0, 1] - Eligibility trace (lambda) for updating Stage 1 values from Stage 2 prediction errors.
    stickiness_1: [-5, 5] - Bonus added to the Q-value of the previous Stage 1 choice.
    stickiness_2: [-5, 5] - Bonus added to the Q-value of the previous Stage 2 choice.
    """
    lr_pos, lr_neg, decay_rate, beta, w, eligibility, stickiness_1, stickiness_2 = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)

    q_stage1_mf = np.ones(2) * 0.5
    q_stage2_mf = np.ones((2, 2)) * 0.5
    
    prev_a1 = -1
    prev_a2 = np.array([-1, -1])

    for trial in range(n_trials):
        # Stage 1 Policy
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        q1_eff = q_stage1_net.copy()
        if prev_a1 != -1:
            q1_eff[prev_a1] += stickiness_1
            
        exp_q1 = np.exp(beta * q1_eff)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # Stage 2 Policy
        q2_eff = q_stage2_mf[state_idx, :].copy()
        if prev_a2[state_idx] != -1:
            q2_eff[prev_a2[state_idx]] += stickiness_2
            
        exp_q2 = np.exp(beta * q2_eff)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # Decay for unchosen options
        unchosen_a1 = 1 - action_1[trial]
        q_stage1_mf[unchosen_a1] += decay_rate * (0.5 - q_stage1_mf[unchosen_a1])
        
        unchosen_a2 = 1 - action_2[trial]
        q_stage2_mf[state_idx, unchosen_a2] += decay_rate * (0.5 - q_stage2_mf[state_idx, unchosen_a2])
        
        unvisited_state = 1 - state_idx
        q_stage2_mf[unvisited_state, 0] += decay_rate * (0.5 - q_stage2_mf[unvisited_state, 0])
        q_stage2_mf[unvisited_state, 1] += decay_rate * (0.5 - q_stage2_mf[unvisited_state, 1])

        # Stage 1 Update
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        lr1 = lr_pos if delta_stage1 > 0 else lr_neg
        q_stage1_mf[action_1[trial]] += lr1 * delta_stage1

        # Stage 2 Update
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        lr2 = lr_pos if delta_stage2 > 0 else lr_neg
        q_stage2_mf[state_idx, action_2[trial]] += lr2 * delta_stage2

        # Eligibility Trace Update
        q_stage1_mf[action_1[trial]] += eligibility * lr2 * delta_stage2
        
        prev_a1 = action_1[trial]
        prev_a2[state_idx] = action_2[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Hybrid Model with Decay and Separate Stage Temperatures
This model uses separate inverse temperatures (`beta_1` and `beta_2`) for Stage 1 and Stage 2 choice policies. Participants often exhibit different levels of stochasticity (exploration/exploitation trade-off) in their Stage 1 choices (which involve model-based planning) compared to their Stage 2 choices (which are purely model-free).

### Model 3: Hybrid Model with Decay and Separate Stage Learning Rates
Participants may update their beliefs at different speeds depending on the stage of the task. Stage 2 provides direct reward feedback (faster updating expected), while Stage 1 provides state-transition feedback (potentially slower updating). This model introduces `lr_1` and `lr_2` to capture this divergence.
