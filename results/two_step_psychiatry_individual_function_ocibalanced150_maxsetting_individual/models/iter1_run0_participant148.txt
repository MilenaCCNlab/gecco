Here are 3 new cognitive models that build upon the successful hybrid model with eligibility trace. These models explore additional cognitive mechanisms that are commonly observed in the two-step task, such as choice stickiness (perseveration), distinct learning rates across stages, and distinct exploration/exploitation trade-offs (inverse temperatures) across stages.

### Model 1: Hybrid Model with Choice Stickiness
Participants often show a tendency to repeat their previous first-stage choice regardless of the reward outcome, a phenomenon known as choice stickiness or perseveration. This model adds a `rho` parameter to capture this behavior.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Model 1: Hybrid Model with choice stickiness.
    Incorporates a stickiness parameter to capture the tendency to repeat the previous Stage 1 choice,
    independent of reward history.
    
    Bounds:
    alpha: [0, 1] - Learning rate for updating Q-values.
    beta: [0, 10] - Inverse temperature for softmax action selection.
    w: [0, 1] - Weighting of model-based vs model-free values (1 = fully MB, 0 = fully MF).
    lam: [0, 1] - Eligibility trace parameter for Stage 1 MF updates from Stage 2 rewards.
    rho: [-5, 5] - Choice stickiness (positive for perseveration, negative for alternation).
    """
    alpha, beta, w, lam, rho = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))

    for trial in range(n_trials):
        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        q_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        stickiness = np.zeros(2)
        if trial > 0:
            stickiness[action_1[trial - 1]] = 1
            
        logits_1 = beta * q_net + rho * stickiness
        logits_1 -= np.max(logits_1) # for numerical stability
        exp_q1 = np.exp(logits_1)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]

        # policy for the second choice
        logits_2 = beta * q_stage2_mf[state_idx]
        logits_2 -= np.max(logits_2)
        exp_q2 = np.exp(logits_2)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        # action value updating for choice 1
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += alpha * delta_stage1
        
        # action value updating for choice 2
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += alpha * delta_stage2
        
        # eligibility trace update for choice 1
        q_stage1_mf[action_1[trial]] += alpha * lam * delta_stage2

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Hybrid Model with Separate Learning Rates
Participants may update their expectations at different speeds for the first stage (which involves abstract transitions) compared to the second stage (which yields immediate rewards). This model disentangles the learning rates for Stage 1 and Stage 2.

### Model 3: Hybrid Model with Separate Inverse Temperatures
Participants often exhibit different levels of decision noise (exploration vs exploitation) depending on the stage of the task. This model utilizes separate inverse temperature parameters for Stage 1 and Stage 2.
