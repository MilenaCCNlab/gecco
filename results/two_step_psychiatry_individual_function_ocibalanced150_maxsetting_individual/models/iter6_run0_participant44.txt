### Model 1: Hybrid MB/MF with Separate Betas for Stage 1 and Stage 2
It is common for decision-makers to exhibit different levels of exploration or choice stochasticity at different stages of a task. This model separates the `beta` parameter into `beta_1` for the first-stage choice and `beta_2` for the second-stage choice, alongside general and reward-dependent stickiness.

```python
import numpy as np

def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Model 1: Hybrid MB/MF with separate inverse temperatures for stage 1 and stage 2,
    plus general choice stickiness and reward-dependent stickiness.
    
    Bounds:
    learning_rate: [0, 1] - Learning rate for updating Q-values.
    beta_1: [0, 10] - Inverse temperature for stage 1 action selection.
    beta_2: [0, 10] - Inverse temperature for stage 2 action selection.
    w: [0, 1] - Weighting parameter for model-based vs model-free influence.
    stickiness: [-5, 5] - General choice stickiness bonus for stage 1.
    reward_stickiness: [-5, 5] - Additional stickiness bonus applied if the previous trial was rewarded.
    """
    learning_rate, beta_1, beta_2, w, stickiness, reward_stickiness = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    last_action_1 = -1
    last_reward = 0

    for trial in range(n_trials):
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        bonus = np.zeros(2)
        if last_action_1 != -1:
            bonus[last_action_1] += stickiness
            if last_reward > 0:
                bonus[last_action_1] += reward_stickiness
            
        exp_q1 = np.exp(beta_1 * q_stage1_net + bonus)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]
        exp_q2 = np.exp(beta_2 * q_stage2_mf[state_idx])
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        
        last_action_1 = action_1[trial]
        last_reward = reward[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Hybrid MB/MF with Stickiness and Action Bias
In the provided data, the participant shows a strong baseline preference for spaceship 0 (chosen ~135 times vs. ~65 times for spaceship 1). This model introduces a `bias` parameter to capture this baseline spatial/stimulus preference, which operates independently of learned values or previous choices.

```python

    """
    Model 2: Hybrid MB/MF with general choice stickiness, reward-dependent stickiness, 
    and a constant bias for choosing spaceship 0.
    
    Bounds:
    learning_rate: [0, 1] - Learning rate for updating Q-values.
    beta: [0, 10] - Inverse temperature for softmax action selection.
    w: [0, 1] - Weighting parameter for model-based vs model-free influence.
    stickiness: [-5, 5] - General choice stickiness bonus for stage 1.
    reward_stickiness: [-5, 5] - Additional stickiness bonus if the previous trial was rewarded.
    bias: [-5, 5] - Constant bias added to the value of action 0 (spaceship 0).
    """
    learning_rate, beta, w, stickiness, reward_stickiness, bias = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
```

### Model 3: Hybrid MB/MF with Eligibility Trace and Separate Betas
This model combines the separate decision noise parameters (from Model 1) with an eligibility trace (`lam`). The eligibility trace allows the final reward prediction error (from the second stage) to feed back directly and update the first-stage model-free Q-value, which is a key component of classic TD(lambda) reinforcement learning.

```python
import numpy as np

def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """
    Model 3: Hybrid MB/MF with an eligibility trace (lambda), separate inverse temperatures 
    for the two stages, and both general and reward-dependent stickiness.
    
    Bounds:
    learning_rate: [0, 1] - Learning rate for updating Q-values.
    beta_1: [0, 10] - Inverse temperature for stage 1.
    beta_2: [0, 10] - Inverse temperature for stage 2.
    w: [0, 1] - Model-based vs model-free weight.
    lam: [0, 1] - Eligibility trace parameter for model-free updates.
    stickiness: [-5, 5] - General choice stickiness bonus for stage 1.
    reward_stickiness: [-5, 5] - Additional stickiness bonus if previous trial was rewarded.
    """
    learning_rate, beta_1, beta_2, w, lam, stickiness, reward_stickiness = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    last_action_1 = -1
    last_reward = 0

    for trial in range(n_trials):
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        bonus = np.zeros(2)
        if last_action_1 != -1:
            bonus[last_action_1] += stickiness
            if last_reward > 0:
                bonus[last_action_1] += reward_stickiness
            
        exp_q1 = np.exp(beta_1 * q_stage1_net + bonus)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]
        exp_q2 = np.exp(beta_2 * q_stage2_mf[state_idx])
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        
        # Eligibility trace update: stage 2 prediction error updates stage 1 model-free Q-value
        q_stage1_mf[action_1[trial]] += learning_rate * lam * delta_stage2
        
        last_action_1 = action_1[trial]
        last_reward = reward[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```
