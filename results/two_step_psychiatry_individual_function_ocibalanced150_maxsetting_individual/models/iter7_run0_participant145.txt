Here are three new cognitive models based on the best-performing structure so far (which uses a single beta, eligibility trace, Q-value decay, and two types of perseveration). These new models explore different variations of learning rate asymmetries and additional perseveration mechanisms while staying within the 8-parameter limit.

### Model 1: Asymmetric Learning Rates (Positive vs. Negative Prediction Errors)
This model builds on the best model by separating the learning rate into `alpha_pos` (for positive reward prediction errors) and `alpha_neg` (for negative reward prediction errors). This accounts for the psychological phenomenon where participants might update their expectations differently when receiving a surprisingly good outcome versus a surprisingly bad one.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Model 1: Single beta for both stages, with action and state perseveration, eligibility trace, and decay.
    Uses separate learning rates for positive and negative prediction errors.
    
    Bounds:
    alpha_pos: [0,1] - learning rate for positive prediction errors
    alpha_neg: [0,1] - learning rate for negative prediction errors
    beta: [0,10] - single inverse temperature for both stages
    w: [0,1] - model-based weight (1 = pure MB, 0 = pure MF)
    lam: [0,1] - eligibility trace
    decay: [0,1] - decay rate for unchosen Q-values
    rep_action: [-5,5] - perseveration on the previous stage 1 choice
    rep_state: [-5,5] - perseveration on the spaceship that commonly leads to previous planet
    """
    alpha_pos, alpha_neg, beta, w, lam, decay, rep_action, rep_state = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action = -1
    last_state = -1

    for trial in range(n_trials):

        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        rep_term = np.zeros(2)
        if last_action != -1:
            rep_term[last_action] += rep_action
            rep_term[last_state] += rep_state
            
        logits1 = beta * q_net + rep_term
        logits1 -= np.max(logits1)
        exp_q1 = np.exp(logits1)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        logits2 = beta * q_stage2_mf[state_idx]
        logits2 -= np.max(logits2)
        exp_q2 = np.exp(logits2)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        alpha1 = alpha_pos if delta_stage1 > 0 else alpha_neg
        q_stage1_mf[action_1[trial]] += alpha1 * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        alpha2 = alpha_pos if delta_stage2 > 0 else alpha_neg
        q_stage2_mf[state_idx, action_2[trial]] += alpha2 * delta_stage2

        # Eligibility trace update to stage 1
        q_stage1_mf[action_1[trial]] += alpha2 * lam * delta_stage2

        unchosen_1 = 1 - action_1[trial]
        q_stage1_mf[unchosen_1] *= (1 - decay)
        
        for s in range(2):
            for a in range(2):
                if not (s == state_idx and a == action_2[trial]):
                    q_stage2_mf[s, a] *= (1 - decay)
                    
        last_action = action_1[trial]
        last_state = state_idx

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Stage-Specific Learning Rates
This model explores the possibility that participants update their values at different speeds for the first step (spaceship choice) versus the second step (alien choice). It modifies the best model by separating the learning rate into `alpha1` and `alpha2`.


### Model 3: Stage 2 Motor Perseveration
This model adds a global motor perseveration term to the second stage (`rep_stage2`), allowing for the possibility that the participant may exhibit a tendency to repeat the same motor response (e.g., choosing the left or right alien) at the second stage regardless of the planet they are on.

```python
def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """
    Model 3: Single beta for both stages, with action and state perseveration, eligibility trace, and decay.
    Adds a global motor perseveration term to the stage 2 choice.
    
    Bounds:
    alpha: [0,1] - learning rate
    beta: [0,10] - single inverse temperature for both stages
    w: [0,1] - model-based weight (1 = pure MB, 0 = pure MF)
    lam: [0,1] - eligibility trace
    decay: [0,1] - decay rate for unchosen Q-values
    rep_action: [-5,5] - perseveration on the previous stage 1 choice
    rep_state: [-5,5] - perseveration on the spaceship that commonly leads to previous planet
    rep_stage2: [-5,5] - perseveration on the previous stage 2 choice
    """
    alpha, beta, w, lam, decay, rep_action, rep_state, rep_stage2 = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action = -1
    last_state = -1
    last_action2 = -1

    for trial in range(n_trials):

        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2

        logits1 -= np.max(logits1)
        exp_q1 = np.exp(logits1)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        rep_term2 = np.zeros(2)
        if last_action2 != -1:
            rep_term2[last_action2] += rep_stage2

        logits2 = beta * q_stage2_mf[state_idx] + rep_term2

        exp_q2 = np.exp(logits2)
        probs_2 = exp_q2 / np.sum(exp_q2)

        unchosen_1 = 1 - action_1[trial]
        q_stage1_mf[unchosen_1] *= (1 - decay)

                    q_stage2_mf[s, a] *= (1 - decay)

        last_state = state_idx

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```
