Here are 3 new cognitive models that explore alternative parameter configurations and mechanisms, building on the best model so far. 

### Model 1: Separate Stage Learning Rates + Reward-Dependent Stickiness
This model expands on the best model so far by decoupling the learning rates for Stage 1 and Stage 2 (`alpha_1` and `alpha_2`). Participants often update their first-stage choices differently than their second-stage choices because the first stage relies on model-based planning and eligibility traces, whereas the second stage is a direct reward update.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Model 1: Separate learning rates for stage 1 and stage 2, combined with 
    reward-dependent stickiness (win-stay/lose-shift).
    
    Parameters:
    alpha_1: [0, 1] - Learning rate for stage 1 Q-values.
    alpha_2: [0, 1] - Learning rate for stage 2 Q-values.
    beta_1: [0, 10] - Inverse temperature for stage 1 choices.
    beta_2: [0, 10] - Inverse temperature for stage 2 choices.
    w: [0, 1] - Model-based weight (1 = fully model-based, 0 = fully model-free).
    lam: [0, 1] - Eligibility trace.
    rep_win: [-5, 5] - Stickiness for stage 1 if the previous trial was rewarded.
    rep_lose: [-5, 5] - Stickiness for stage 1 if the previous trial was unrewarded.
    """
    alpha_1, alpha_2, beta_1, beta_2, w, lam, rep_win, rep_lose = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action_1 = -1
    last_reward = -1

    for trial in range(n_trials):
        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        stickiness = np.zeros(2)
        if last_action_1 != -1:
            if last_reward == 1:
                stickiness[last_action_1] = rep_win
            elif last_reward == 0:
                stickiness[last_action_1] = rep_lose
                
        q1_logits = beta_1 * q_stage1_net + stickiness
        q1_logits -= np.max(q1_logits)
        exp_q1 = np.exp(q1_logits)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]

        # policy for the second choice
        q2_logits = beta_2 * q_stage2_mf[state_idx]
        q2_logits -= np.max(q2_logits)
        exp_q2 = np.exp(q2_logits)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # Action value updating for choice 1
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += alpha_1 * delta_stage1
        
        # Action value updating for choice 2
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += alpha_2 * delta_stage2
        
        # Eligibility trace updating for choice 1
        q_stage1_mf[action_1[trial]] += alpha_1 * lam * delta_stage2
        
        last_action_1 = action_1[trial]
        last_reward = reward[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Asymmetric Learning Rates + Reward-Dependent Stickiness
This model investigates whether participants update their expectations differently for positive versus negative surprise (asymmetric learning). It merges `alpha_pos` and `alpha_neg` with the highly effective `rep_win` and `rep_lose` mechanism.

```python
def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """
    Model 2: Asymmetric learning rates for positive and negative prediction errors, 
    combined with reward-dependent stickiness.
    
    Parameters:
    alpha_pos: [0, 1] - Learning rate for positive prediction errors.
    alpha_neg: [0, 1] - Learning rate for negative prediction errors.
    beta_1: [0, 10] - Inverse temperature for stage 1 choices.
    beta_2: [0, 10] - Inverse temperature for stage 2 choices.
    w: [0, 1] - Model-based weight (1 = fully model-based, 0 = fully model-free).
    lam: [0, 1] - Eligibility trace.
    rep_win: [-5, 5] - Stickiness for stage 1 if the previous trial was rewarded.
    rep_lose: [-5, 5] - Stickiness for stage 1 if the previous trial was unrewarded.
    """

        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]

        q_stage1_mf[action_1[trial]] += alpha_stage1 * lam * delta_stage2
        
        last_action_1 = action_1[trial]
        last_reward = reward[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 3: Asymmetric Eligibility Traces
This model proposes a novel mechanism: participants might project reward prediction errors back to their first-stage choices asymmetrically (`lam_pos` vs `lam_neg`). They might "credit" their initial choice more strongly when they receive an unexpected reward, compared to when they experience an unexpected omission of reward.

```python
def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """
    Model 3: Separate learning rates for stage 1 and 2, with asymmetric eligibility 
    traces for positive versus negative reward prediction errors.
    
    Parameters:
    alpha_1: [0, 1] - Learning rate for stage 1 Q-values.
    alpha_2: [0, 1] - Learning rate for stage 2 Q-values.
    beta_1: [0, 10] - Inverse temperature for stage 1 choices.
    beta_2: [0, 10] - Inverse temperature for stage 2 choices.
    w: [0, 1] - Model-based weight (1 = fully model-based, 0 = fully model-free).
    lam_pos: [0, 1] - Eligibility trace for positive stage 2 RPEs.
    lam_neg: [0, 1] - Eligibility trace for negative stage 2 RPEs.
    rep: [-5, 5] - General stickiness for stage 1 choices.
    """
    alpha_1, alpha_2, beta_1, beta_2, w, lam_pos, lam_neg, rep = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)

    q_stage2_mf = np.zeros((2, 2))
```
