Here are 3 new cognitive models that build upon the best-performing model by integrating novel mechanisms while keeping the parameter count parsimonious (exactly 8 parameters each). To achieve this, these models use a single shared inverse temperature (`beta`) for both decision stages, which frees up a parameter to explore new dynamics alongside the successful `decay` and `q0` mechanisms.

### Model 1: Shared Temperature + Reward Sensitivity
This model uses a shared inverse temperature (`beta`) and introduces a reward sensitivity parameter (`rho`). Because Q-values decay towards a fixed baseline `q0`, scaling the reward with `rho` allows the model to dynamically adjust the magnitude of learned Q-values relative to the unlearned baseline `q0` and choice stickiness `pi`.

```python
import numpy as np

def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Model 1: Daw et al. (2011) model with decay towards a baseline value q0, 
    a single shared inverse temperature beta, and a reward sensitivity parameter rho.
    
    Bounds:
    alpha: [0, 1] - learning rate
    beta: [0, 10] - shared inverse temperature for stage 1 and stage 2
    w: [0, 1] - model-based weight
    lambda_: [0, 1] - eligibility trace
    pi: [-5, 5] - stage 1 choice stickiness
    decay: [0, 1] - decay rate for unchosen options
    q0: [0, 1] - baseline value to decay towards
    rho: [0, 10] - reward sensitivity (multiplier on reward)
    """
    alpha, beta, w, lambda_, pi, decay, q0, rho = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)

    q_stage1_mf = np.full(2, float(q0))
    q_stage2_mf = np.full((2, 2), float(q0))
    last_a1 = -1

    for trial in range(n_trials):
        if action_1[trial] == -1 or action_2[trial] == -1:
            p_choice_1[trial] = 1.0
            p_choice_2[trial] = 1.0
            continue
            
        a1 = action_1[trial]
        a2 = action_2[trial]
        state_idx = state[trial]
        
        # Scale reward by sensitivity parameter
        r = reward[trial] * rho

        # Stage 1 Policy
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        rep = np.zeros(2)
        if last_a1 != -1:
            rep[last_a1] = 1.0
            
        q1_scaled = beta * q_stage1_net + pi * rep
        q1_scaled -= np.max(q1_scaled)
        exp_q1 = np.exp(q1_scaled)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[a1]

        # Stage 2 Policy
        q2_scaled = beta * q_stage2_mf[state_idx]
        q2_scaled -= np.max(q2_scaled)
        exp_q2 = np.exp(q2_scaled)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[a2]

        # Update Q-values
        delta_stage1 = q_stage2_mf[state_idx, a2] - q_stage1_mf[a1]
        q_stage1_mf[a1] += alpha * delta_stage1
        
        delta_stage2 = r - q_stage2_mf[state_idx, a2]
        q_stage2_mf[state_idx, a2] += alpha * delta_stage2
        
        q_stage1_mf[a1] += alpha * lambda_ * delta_stage2

        # Decay unchosen options towards q0
        unchosen_a1 = 1 - a1
        q_stage1_mf[unchosen_a1] += decay * (q0 - q_stage1_mf[unchosen_a1])
        
        for s in range(2):
            for a in range(2):
                if not (s == state_idx and a == a2):
                    q_stage2_mf[s, a] += decay * (q0 - q_stage2_mf[s, a])
        
        last_a1 = a1

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Shared Temperature + Win-Stay / Lose-Shift Stickiness
Participants often show different tendencies to repeat an action depending on whether the previous trial was rewarded or not. This model separates the Stage 1 stickiness parameter into `pi_win` and `pi_lose` to capture asymmetric choice perseveration.

```python
import numpy as np

def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """
    Model 2: Daw et al. (2011) model with decay towards a baseline value q0,
    a single shared inverse temperature beta, and separate stickiness parameters 
    for when the previous trial was rewarded (pi_win) vs unrewarded (pi_lose).
    
    Bounds:
    alpha: [0, 1] - learning rate
    beta: [0, 10] - shared inverse temperature for stage 1 and stage 2
    w: [0, 1] - model-based weight
    lambda_: [0, 1] - eligibility trace
    pi_win: [-5, 5] - stage 1 choice stickiness if previous trial was rewarded
    pi_lose: [-5, 5] - stage 1 choice stickiness if previous trial was unrewarded
    decay: [0, 1] - decay rate for unchosen options
    q0: [0, 1] - baseline value to decay towards
    """
    alpha, beta, w, lambda_, pi_win, pi_lose, decay, q0 = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)

    q_stage1_mf = np.full(2, float(q0))
    q_stage2_mf = np.full((2, 2), float(q0))
    last_a1 = -1
    last_reward = 0

    for trial in range(n_trials):
        if action_1[trial] == -1 or action_2[trial] == -1:
            p_choice_1[trial] = 1.0
            p_choice_2[trial] = 1.0
            continue
            
        a1 = action_1[trial]
        a2 = action_2[trial]
        state_idx = state[trial]
        r = reward[trial]

        # Stage 1 Policy
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        rep = np.zeros(2)
        if last_a1 != -1:
            rep[last_a1] = 1.0
            
        current_pi = pi_win if last_reward > 0 else pi_lose
        
        q1_scaled = beta * q_stage1_net + current_pi * rep
        q1_scaled -= np.max(q1_scaled)
        exp_q1 = np.exp(q1_scaled)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[a1]

        # Stage 2 Policy
        q2_scaled = beta * q_stage2_mf[state_idx]
        q2_scaled -= np.max(q2_scaled)
        exp_q2 = np.exp(q2_scaled)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[a2]

        # Update Q-values
        delta_stage1 = q_stage2_mf[state_idx, a2] - q_stage1_mf[a1]
        q_stage1_mf[a1] += alpha * delta_stage1
        
        delta_stage2 = r - q_stage2_mf[state_idx, a2]
        q_stage2_mf[state_idx, a2] += alpha * delta_stage2
        
        q_stage1_mf[a1] += alpha * lambda_ * delta_stage2

        # Decay unchosen options towards q0
        unchosen_a1 = 1 - a1
        q_stage1_mf[unchosen_a1] += decay * (q0 - q_stage1_mf[unchosen_a1])
        
        for s in range(2):
            for a in range(2):
                if not (s == state_idx and a == a2):
                    q_stage2_mf[s, a] += decay * (q0 - q_stage2_mf[s, a])
        
        last_a1 = a1
        last_reward = r

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 3: Shared Temperature + Stage-Specific Learning Rates
This model introduces separate learning rates for Stage 1 (`alpha_1`) and Stage 2 (`alpha_2`). Because the first stage entails choosing a spaceship while the second stage entails choosing an alien whose reward probabilities drift, participants might update their expectations at different speeds for these two steps.

```python

    Model 3: Daw et al. (2011) model with decay towards a baseline value q0,
    a single shared inverse temperature beta, and separate learning rates 
    for stage 1 (alpha_1) and stage 2 (alpha_2).
    
    Bounds:
    alpha_1: [0, 1] - learning rate for stage 1
    alpha_2: [0, 1] - learning rate for stage 2
    beta: [0, 10] - shared inverse temperature for stage 1 and stage 2
    w: [0, 1] - model-based weight
    lambda_: [0, 1] - eligibility trace
    pi: [-5, 5] - stage 1 choice stickiness
    decay: [0, 1] - decay rate for unchosen options
    q0: [0, 1] - baseline value to decay towards

    q_stage1_mf = np.full(2, float(q0))
```
