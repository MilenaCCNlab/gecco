Here are three new cognitive models that build upon the success of the penalty mechanism (which treats 0-coin outcomes as a negative penalty) by combining it with other cognitive mechanisms. These parameter combinations explore different ways participants might process positive versus negative feedback and update their internal models.

### Model 1: Asymmetric Learning Rates + Negative Reward Penalty
This model incorporates the `penalty` mechanism and pairs it with asymmetric learning rates (`alpha_pos` and `alpha_neg`). Participants often update their expectations differently when receiving better-than-expected versus worse-than-expected outcomes.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Model 1: Asymmetric Learning Rates + Negative Reward Penalty
    
    This model uses separate learning rates for positive and negative prediction errors,
    and treats unrewarded outcomes (0 coins) as a negative penalty.
    
    Bounds:
    alpha_pos: [0,1] - Learning rate for positive PE
    alpha_neg: [0,1] - Learning rate for negative PE
    beta: [0,10] - Inverse temperature for stage 1
    beta2: [0,10] - Inverse temperature for stage 2
    w: [0,1] - Weighting of MB vs MF control
    lam: [0,1] - Eligibility trace
    stick1: [-5,5] - Choice stickiness for stage 1
    penalty: [0,5] - Penalty for unrewarded outcomes (0 becomes -penalty)
    """
    import numpy as np
    alpha_pos, alpha_neg, beta, beta2, w, lam, stick1, penalty = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action_1 = -1

    for trial in range(n_trials):
        if action_1[trial] == -1 or action_2[trial] == -1:
            p_choice_1[trial] = 1.0
            p_choice_2[trial] = 1.0
            continue

        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2

        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        if last_action_1 != -1:
            q_stage1_net[last_action_1] += stick1
            
        q_stage1_net = q_stage1_net - np.max(q_stage1_net)
        exp_q1 = np.exp(beta * q_stage1_net)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]

        q2_net = np.copy(q_stage2_mf[state_idx])
        q2_net = q2_net - np.max(q2_net)
        exp_q2 = np.exp(beta2 * q2_net)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # Stage 1 update
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        lr1 = alpha_pos if delta_stage1 > 0 else alpha_neg
        q_stage1_mf[action_1[trial]] += lr1 * delta_stage1

        # Stage 2 update
        eff_reward = reward[trial] if reward[trial] > 0 else -penalty
        delta_stage2 = eff_reward - q_stage2_mf[state_idx, action_2[trial]]
        lr2 = alpha_pos if delta_stage2 > 0 else alpha_neg
        q_stage2_mf[state_idx, action_2[trial]] += lr2 * delta_stage2
        
        # Eligibility trace update to Stage 1
        q_stage1_mf[action_1[trial]] += lr2 * lam * delta_stage2
        
        last_action_1 = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Transition Learning + Negative Reward Penalty
Instead of assuming a fixed 0.7/0.3 transition structure, this model posits that participants dynamically learn and update the transition matrix over time using `alpha_trans`. 

```python
def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """
    Model 2: Transition Learning + Negative Reward Penalty
    
    This model updates the transition matrix based on observed transitions,
    and uses a penalty for unrewarded outcomes.
    
    Bounds:
    learning_rate: [0,1] - Learning rate for Q-values
    alpha_trans: [0,1] - Learning rate for transition matrix
    beta: [0,10] - Inverse temperature for stage 1
    beta2: [0,10] - Inverse temperature for stage 2
    w: [0,1] - Weighting of MB vs MF control
    lam: [0,1] - Eligibility trace
    stick1: [-5,5] - Choice stickiness for stage 1
    penalty: [0,5] - Penalty for unrewarded outcomes (0 becomes -penalty)
    """
    import numpy as np
    learning_rate, alpha_trans, beta, beta2, w, lam, stick1, penalty = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action_1 = -1

    for trial in range(n_trials):
        if action_1[trial] == -1 or action_2[trial] == -1:
            p_choice_1[trial] = 1.0
            p_choice_2[trial] = 1.0
            continue

        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2

        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        if last_action_1 != -1:
            q_stage1_net[last_action_1] += stick1
            
        q_stage1_net = q_stage1_net - np.max(q_stage1_net)
        exp_q1 = np.exp(beta * q_stage1_net)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        
        state_idx = state[trial]

        q2_net = np.copy(q_stage2_mf[state_idx])
        q2_net = q2_net - np.max(q2_net)
        exp_q2 = np.exp(beta2 * q2_net)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # Transition matrix update
        transition_matrix[action_1[trial], state_idx] += alpha_trans * (1.0 - transition_matrix[action_1[trial], state_idx])
        transition_matrix[action_1[trial], 1 - state_idx] += alpha_trans * (0.0 - transition_matrix[action_1[trial], 1 - state_idx])

        # Stage 1 update
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1

        # Stage 2 update
        eff_reward = reward[trial] if reward[trial] > 0 else -penalty
        delta_stage2 = eff_reward - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        
        # Eligibility trace
        q_stage1_mf[action_1[trial]] += learning_rate * lam * delta_stage2
        
        last_action_1 = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 3: Asymmetric Eligibility Traces + Negative Reward Penalty
This model allows the credit assignment (the eligibility trace mapping Stage 2 prediction errors back to Stage 1 choices) to differ depending on whether the Stage 2 prediction error is positive or negative. This captures asymmetric reinforcement of preceding choices based on valence.

    to stage 1 to differ depending on whether the stage 2 prediction error 
    is positive or negative, capturing asymmetric reinforcement of initial choices.

    learning_rate: [0,1] - Learning rate
