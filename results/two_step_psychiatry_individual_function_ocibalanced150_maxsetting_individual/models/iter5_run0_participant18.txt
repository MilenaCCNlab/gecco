Here are 3 new cognitive models proposing alternative parameter configurations built on top of the successful Q-value decay mechanism. 

### Model 1: Hybrid Model with Decay and Separate Stage Temperatures
This model uses the successful decay mechanism but introduces separate inverse temperatures (`beta1` and `beta2`) for stage 1 and stage 2 choices. Participants often exhibit different levels of choice stochasticity in the two stages (e.g., more exploration in stage 1, more exploitation in stage 2), which a single beta parameter cannot capture.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Hybrid Model with Q-value Decay and separate choice temperatures for Stage 1 and Stage 2.
    
    Bounds:
    alpha: [0, 1] - Learning rate for updating Q-values.
    beta1: [0, 10] - Inverse temperature for softmax choice in Stage 1.
    beta2: [0, 10] - Inverse temperature for softmax choice in Stage 2.
    w: [0, 1] - Weighting of model-based vs model-free control (1=pure MB, 0=pure MF).
    pi: [-5, 5] - Perseveration bonus for repeating the previous stage 1 choice.
    lambda_: [0, 1] - Eligibility trace for stage 1 model-free update.
    decay: [0, 1] - Rate at which Q-values decay towards 0 on each trial.
    """
    import numpy as np
    alpha, beta1, beta2, w, pi, lambda_, decay = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action_1 = -1

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        q_net = w * q_stage1_mb + (1 - w) * q_stage1_mf

        pers = np.zeros(2)
        if last_action_1 != -1:
            pers[last_action_1] = 1
            
        logits_1 = beta1 * q_net + pi * pers
        logits_1 -= np.max(logits_1) # Prevent overflow
        exp_q1 = np.exp(logits_1)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        logits_2 = beta2 * q_stage2_mf[state_idx]
        logits_2 -= np.max(logits_2)
        exp_q2 = np.exp(logits_2)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # decay unchosen and chosen options prior to update
        q_stage1_mf = q_stage1_mf * (1 - decay)
        q_stage2_mf = q_stage2_mf * (1 - decay)

        # action value updating
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += alpha * delta_stage1

        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += alpha * delta_stage2

        q_stage1_mf[action_1[trial]] += alpha * lambda_ * delta_stage2
        
        last_action_1 = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Hybrid Model with Decay and Separate Stage Learning Rates
This model introduces separate learning rates (`alpha1` and `alpha2`) for the two stages, alongside decay. Prediction errors in stage 1 are driven by expected values in stage 2, whereas stage 2 prediction errors are driven by primary rewards. Participants might update these distinct types of information at different speeds.

### Model 3: Hybrid Model with Decay and Reward Sensitivity
This model incorporates `rho`, a reward sensitivity parameter. When decay is active, values inherently shrink over time. A reward multiplier scales the magnitude of updates against the constant downward pressure of decay and static perseveration values, altering steady-state Q-values based on subjective valuation of the reward. 

```python
def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """
    Hybrid Model with Q-value Decay and Subjective Reward Sensitivity.
    
    Bounds:
    alpha: [0, 1] - Learning rate for updating Q-values.
    beta: [0, 10] - Inverse temperature for softmax choice.
    w: [0, 1] - Weighting of model-based vs model-free control.
    pi: [-5, 5] - General perseveration bonus for repeating the previous stage 1 choice.
    lambda_: [0, 1] - Eligibility trace for stage 1 model-free update.
    decay: [0, 1] - Rate at which Q-values decay towards 0 on each trial.
    rho: [0, 5] - Reward sensitivity multiplier scaling the subjective value of points.
    """
    import numpy as np
    alpha, beta, w, pi, lambda_, decay, rho = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action_1 = -1

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        q_net = w * q_stage1_mb + (1 - w) * q_stage1_mf

        pers = np.zeros(2)
        if last_action_1 != -1:
            pers[last_action_1] = 1
            
        logits_1 = beta * q_net + pi * pers
        logits_1 -= np.max(logits_1) # Prevent overflow
        exp_q1 = np.exp(logits_1)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        logits_2 = beta * q_stage2_mf[state_idx]
        logits_2 -= np.max(logits_2)
        exp_q2 = np.exp(logits_2)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # decay unchosen and chosen options prior to update
        q_stage1_mf = q_stage1_mf * (1 - decay)
        q_stage2_mf = q_stage2_mf * (1 - decay)

        # action value updating with reward scaling
        effective_reward = reward[trial] * rho
        
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += alpha * delta_stage1

        delta_stage2 = effective_reward - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += alpha * delta_stage2

        q_stage1_mf[action_1[trial]] += alpha * lambda_ * delta_stage2
        
        last_action_1 = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```
