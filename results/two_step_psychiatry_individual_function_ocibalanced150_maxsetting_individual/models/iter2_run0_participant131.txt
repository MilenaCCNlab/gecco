Here are 3 new cognitive models that propose novel mechanisms for how participants make decisions in this two-step task. Each model strictly adheres to the provided template structure and introduces new dynamics without repeating previously tried parameter combinations.

### Model 1: Anti-correlated Belief Update (Fictitious Learning)
Participants often assume that if one alien on a planet yields a reward, the other alien is less likely to do so, and vice versa. This model captures that assumption by applying a "fictitious update" to the unchosen alien on the visited planet, updating it as if it yielded the exact opposite outcome of the chosen alien.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """Model 1: Anti-correlated Belief Update (Fictitious Learning).
    
    This model assumes participants believe the reward probabilities of the two 
    aliens on the same planet are anti-correlated. When they receive a reward 
    from the chosen alien, they update the unchosen alien on the same planet 
    as if it yielded the opposite outcome.
    
    Parameters:
    learning_rate: [0, 1] - Learning rate for the chosen action.
    fictitious_rate: [0, 1] - Learning rate for the unchosen action's inferred outcome.
    beta: [0, 10] - Inverse temperature for softmax action selection.
    """
    learning_rate, fictitious_rate, beta = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        exp_q1 = np.exp(beta * q_stage1_mb)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta * q_stage2_mf[state_idx])
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        
        # Fictitious update for unchosen alien on the visited planet
        unchosen_a2 = 1 - action_2[trial]
        fictitious_reward = 1 - reward[trial]
        delta_fict = fictitious_reward - q_stage2_mf[state_idx, unchosen_a2]
        q_stage2_mf[state_idx, unchosen_a2] += fictitious_rate * delta_fict

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Mean-Reverting Q-values 
Because the task instructions specify that reward probabilities change slowly over time, participants might assume that unvisited planets and unchosen aliens drift back toward a random chance level (0.5). This model implements a mean-reverting drift for all unchosen options at every trial.

```python
def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """Model 2: Mean-Reverting Q-values.
    
    Participants know that alien reward probabilities change slowly over time. 
    This model captures the assumption that unobserved aliens' reward probabilities 
    drift back towards 0.5 (chance). At each trial, unchosen Q-values drift toward 0.5.
    
    Parameters:
    learning_rate: [0, 1] - Learning rate for Q-value updates based on reward.
    drift_rate: [0, 1] - Rate at which unchosen Q-values revert to 0.5.
    beta: [0, 10] - Inverse temperature for softmax action selection.
    """
    learning_rate, drift_rate, beta = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        exp_q1 = np.exp(beta * q_stage1_mb)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta * q_stage2_mf[state_idx])
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        
        # Drift unchosen Q-values towards 0.5
        for s in range(2):
            for a in range(2):
                if s != state_idx or a != action_2[trial]:
                    q_stage2_mf[s, a] += drift_rate * (0.5 - q_stage2_mf[s, a])

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 3: Outcome-Dependent Perseveration (Win-Stay, Lose-Shift)
Often, behavior is guided by simpler heuristics acting alongside standard Q-learning. This model adds a direct, outcome-dependent bias to the Stage 2 choices. If the participant lands on the same planet as the previous trial, they apply a "win-stay" bonus to their previous choice if it was rewarded, or a "lose-shift" penalty if it yielded nothing.

```python
def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """Model 3: Outcome-Dependent Perseveration (Win-Stay, Lose-Shift).
    
    This model adds outcome-dependent biases to Stage 2 choices. If the participant 
    returns to the same planet as the previous trial, their choice is biased by 
    the previous outcome: a reward increases the probability of repeating the 
    choice (win-stay), while a lack of reward decreases it (lose-shift).
    
    Parameters:
    learning_rate: [0, 1] - Learning rate for Q-value updates.
    win_stay: [0, 5] - Bonus applied to the previous action if it was rewarded.
    lose_shift: [0, 5] - Penalty applied to the previous action if it was unrewarded.
    beta: [0, 10] - Inverse temperature for softmax action selection.
    """
    learning_rate, win_stay, lose_shift, beta = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    prev_state = -1
    prev_action_2 = -1
    prev_reward = -1

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        exp_q1 = np.exp(beta * q_stage1_mb)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        logits_2 = beta * np.copy(q_stage2_mf[state_idx])
        if state_idx == prev_state:
            if prev_reward == 1:
                logits_2[prev_action_2] += win_stay
            elif prev_reward == 0:
                logits_2[prev_action_2] -= lose_shift
                
        exp_q2 = np.exp(logits_2 - np.max(logits_2)) # max subtraction for numerical stability
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]
  
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += learning_rate * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += learning_rate * delta_stage2
        
        prev_state = state_idx
        prev_action_2 = action_2[trial]
        prev_reward = reward[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```
