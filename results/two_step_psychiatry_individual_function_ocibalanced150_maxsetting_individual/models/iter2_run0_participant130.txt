Here are 3 new cognitive models that expand upon the best model so far by exploring different mechanisms, while retaining the successful dual choice stickiness (perseveration) at both decision stages.

### Model 1: Hybrid MB/MF RL with Dual Stickiness and Q-Value Decay
This model tests the hypothesis that the participant's Q-values gradually drift towards a neutral point (0.5) over time if they are not chosen. This models a memory decay or a gradual increase in uncertainty about the unchosen options.

```python
import numpy as np

def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """Model 1: Hybrid MB/MF RL with dual stickiness and decay of unchosen Q-values.
    
    Parameters:
    alpha: [0,1] - Learning rate for Q-value updating.
    beta: [0,10] - Inverse temperature for softmax action selection.
    w: [0,1] - Weighting between model-based (1) and model-free (0) strategies.
    lam: [0,1] - Eligibility trace parameter for updating stage 1 with stage 2 prediction error.
    rho_1: [0,10] - Choice stickiness parameter for stage 1 actions.
    rho_2: [0,10] - Choice stickiness parameter for stage 2 actions, conditional on the state.
    decay: [0,1] - Decay rate for all Q-values towards 0.5 before updating.
    """
    alpha, beta, w, lam, rho_1, rho_2, decay = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    
    # Initialize values to 0.5 since they decay towards this neutral baseline
    q_stage1_mf = np.zeros(2) + 0.5
    q_stage2_mf = np.zeros((2, 2)) + 0.5
    
    last_choice_1 = -1
    last_choice_2 = [-1, -1] 

    for trial in range(n_trials):
        # Stage 1 Policy
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        stickiness_1 = np.zeros(2)
        if last_choice_1 != -1:
            stickiness_1[last_choice_1] = 1.0
            
        v1 = beta * q_net + rho_1 * stickiness_1
        exp_q1 = np.exp(v1 - np.max(v1)) # Subtract max for numerical stability
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # Stage 2 Policy
        stickiness_2 = np.zeros(2)
        if last_choice_2[state_idx] != -1:
            stickiness_2[last_choice_2[state_idx]] = 1.0

        v2 = beta * q_stage2_mf[state_idx, :] + rho_2 * stickiness_2
        exp_q2 = np.exp(v2 - np.max(v2))
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # Decay all Q-values before specific updating
        q_stage1_mf = (1 - decay) * q_stage1_mf + decay * 0.5
        q_stage2_mf = (1 - decay) * q_stage2_mf + decay * 0.5

        # Value Updating
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += alpha * delta_stage1

        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += alpha * delta_stage2

        q_stage1_mf[action_1[trial]] += alpha * lam * delta_stage2
        
        last_choice_1 = action_1[trial]
        last_choice_2[state_idx] = action_2[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```


### Model 2: Asymmetric Learning Rates (Positive vs. Negative Prediction Errors)
This model tests whether the participant evaluates rewarding and unrewarding outcomes differently by applying distinct learning rates to positive and negative prediction errors. This is a common feature in psychiatric/computational analyses of reinforcement learning.

```python
import numpy as np

def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """Model 2: Hybrid MB/MF RL with asymmetric learning rates (positive vs negative PE) and dual stickiness.
    
    Parameters:
    alpha_pos: [0,1] - Learning rate for positive prediction errors (better than expected).
    alpha_neg: [0,1] - Learning rate for negative prediction errors (worse than expected).
    beta: [0,10] - Inverse temperature for softmax action selection.
    w: [0,1] - Weighting between model-based (1) and model-free (0) strategies.
    lam: [0,1] - Eligibility trace parameter for updating stage 1 with stage 2 prediction error.
    rho_1: [0,10] - Choice stickiness parameter for stage 1 actions.
    rho_2: [0,10] - Choice stickiness parameter for stage 2 actions, conditional on the state.
    """
    alpha_pos, alpha_neg, beta, w, lam, rho_1, rho_2 = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_choice_1 = -1
    last_choice_2 = [-1, -1]

    for trial in range(n_trials):
        # Stage 1 Policy
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        stickiness_1 = np.zeros(2)
        if last_choice_1 != -1:
            stickiness_1[last_choice_1] = 1.0
            
        v1 = beta * q_net + rho_1 * stickiness_1
        exp_q1 = np.exp(v1 - np.max(v1))
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # Stage 2 Policy
        stickiness_2 = np.zeros(2)
        if last_choice_2[state_idx] != -1:
            stickiness_2[last_choice_2[state_idx]] = 1.0

        v2 = beta * q_stage2_mf[state_idx, :] + rho_2 * stickiness_2
        exp_q2 = np.exp(v2 - np.max(v2))
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # Value Updating with Asymmetric Learning Rates
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        alpha_1 = alpha_pos if delta_stage1 > 0 else alpha_neg
        q_stage1_mf[action_1[trial]] += alpha_1 * delta_stage1

        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        alpha_2 = alpha_pos if delta_stage2 > 0 else alpha_neg
        q_stage2_mf[state_idx, action_2[trial]] += alpha_2 * delta_stage2

        alpha_lam = alpha_pos if delta_stage2 > 0 else alpha_neg
        q_stage1_mf[action_1[trial]] += alpha_lam * lam * delta_stage2
        
        last_choice_1 = action_1[trial]
        last_choice_2[state_idx] = action_2[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```


### Model 3: Separate Temperatures for First and Second Stage Decisions
This variation explores whether the participant's decision noise (exploration vs exploitation tradeoff) is systematically different between the high-level spaceship choice (Stage 1) and the final alien choice (Stage 2).

```python

    """Model 3: Hybrid MB/MF RL with separate inverse temperatures for stage 1 and stage 2, and dual stickiness.
    
    Parameters:
    alpha: [0,1] - Learning rate for Q-value updating.
    beta_1: [0,10] - Inverse temperature for stage 1 softmax action selection.
    beta_2: [0,10] - Inverse temperature for stage 2 softmax action selection.
    w: [0,1] - Weighting between model-based (1) and model-free (0) strategies.
    lam: [0,1] - Eligibility trace parameter for updating stage 1 with stage 2 prediction error.
    rho_1: [0,10] - Choice stickiness parameter for stage 1 actions.
    rho_2: [0,10] - Choice stickiness parameter for stage 2 actions, conditional on the state.
    """
    alpha, beta_1, beta_2, w, lam, rho_1, rho_2 = model_parameters

    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)

    q_stage2_mf = np.zeros((2, 2))
```
