Here are 3 new cognitive models that explore different psychological mechanisms not yet tested in your list. They extend the best-performing hybrid model with choice perseveration by incorporating time-varying exploration, reward-dependent exploration, and transition-dependent learning rates.

### Model 1: Time-Varying Inverse Temperature (Fatigue/Learning Model)
Participants often change their decision-making strategy over the course of a task. They might start by exploring randomly and become more deterministic as they learn the task (increasing $\beta$), or they might start focused but become fatigued and random towards the end (decreasing $\beta$). This model allows the inverse temperature to change linearly over time.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Time-Varying Beta Model.
    
    This model allows the inverse temperature (beta) to change linearly over the course 
    of the task, capturing changes in exploration/exploitation due to learning or fatigue.
    
    Parameters:
    model_parameters: list or array containing:
        alpha: [0, 1] - Learning rate for updating Q-values.
        beta_start: [0, 10] - Inverse temperature at the beginning of the task.
        beta_end: [0, 10] - Inverse temperature at the end of the task.
        w: [0, 1] - Weighting of model-based vs model-free values.
        lambda_: [0, 1] - Eligibility trace parameter.
        pi: [-5, 5] - Choice perseverance (stickiness) parameter for stage 1. Positive values indicate a tendency to repeat the last action.
    """
    alpha, beta_start, beta_end, w, lambda_, pi = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action = None

    for trial in range(n_trials):
        # Calculate current beta based on trial number
        beta_t = beta_start + (beta_end - beta_start) * (trial / max(1, n_trials - 1))

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf

        if last_action is not None:
            q_stage1_net[last_action] += pi
            
        exp_q1 = np.exp(beta_t * (q_stage1_net - np.max(q_stage1_net)))
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta_t * (q_stage2_mf[state_idx] - np.max(q_stage2_mf[state_idx])))
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # action value updating
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += alpha * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += alpha * delta_stage2

        q_stage1_mf[action_1[trial]] += alpha * lambda_ * delta_stage2
        
        last_action = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Reward-Dependent Exploration (Win-Stay/Lose-Explore)
Instead of a simple "win-stay, lose-shift" heuristic for choices, participants might modulate their overall *level of exploration* based on recent rewards. After receiving a reward, they might enter an exploitative state (high $\beta$). After a non-reward, they might increase their behavioral noise to explore alternatives (low $\beta$).

```python
def cognitive_model2(action_1, state, action_2, reward, model_parameters):
    """
    Reward-Dependent Exploration (Beta) Model.
    
    This model assumes that participants change their exploration rate depending on 
    whether the previous trial was rewarded. After a reward, they might exploit (higher beta), 
    and after a non-reward, they might explore (lower beta).
    
    Parameters:
    model_parameters: list or array containing:
        alpha: [0, 1] - Learning rate for updating Q-values.
        beta_win: [0, 10] - Inverse temperature following a rewarded trial.
        beta_lose: [0, 10] - Inverse temperature following an unrewarded trial.
        w: [0, 1] - Weighting of model-based vs model-free values.
        lambda_: [0, 1] - Eligibility trace parameter.
        pi: [-5, 5] - Choice perseverance (stickiness) parameter for stage 1.
    """
    alpha, beta_win, beta_lose, w, lambda_, pi = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action = None
    last_reward = None

    for trial in range(n_trials):
        # Determine current beta based on previous reward
        if last_reward is None:
            beta_t = (beta_win + beta_lose) / 2.0
        elif last_reward > 0:
            beta_t = beta_win
        else:
            beta_t = beta_lose

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf

        if last_action is not None:
            q_stage1_net[last_action] += pi
            
        exp_q1 = np.exp(beta_t * (q_stage1_net - np.max(q_stage1_net)))
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta_t * (q_stage2_mf[state_idx] - np.max(q_stage2_mf[state_idx])))
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # action value updating
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += alpha * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += alpha * delta_stage2

        q_stage1_mf[action_1[trial]] += alpha * lambda_ * delta_stage2
        
        last_action = action_1[trial]
        last_reward = reward[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 3: Transition-Dependent Learning Rate (Surprise Modulation)
In cognitive science, the Pearce-Hall theory suggests that surprising events increase attention and therefore the learning rate. Conversely, some participants might discount rare transitions as "noise" and lower their learning rate. This model tests whether learning rates for value updates vary based on whether the state transition was common (expected) or rare (surprising).

```python
def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """
    Transition-Dependent Learning Rate Model.
    
    This model allows for different learning rates depending on whether the transition 
    from stage 1 to stage 2 was common or rare. Participants might update values differently 
    when the outcome state is surprising.
    
    Parameters:
    model_parameters: list or array containing:
        alpha_common: [0, 1] - Learning rate after a common transition.
        alpha_rare: [0, 1] - Learning rate after a rare transition.
        beta: [0, 10] - Inverse temperature for softmax action selection.
        w: [0, 1] - Weighting of model-based vs model-free values.
        lambda_: [0, 1] - Eligibility trace parameter.
        pi: [-5, 5] - Choice perseverance (stickiness) parameter for stage 1.
    """
    alpha_common, alpha_rare, beta, w, lambda_, pi = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action = None

    for trial in range(n_trials):

        # policy for the first choice
        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf

        if last_action is not None:
            q_stage1_net[last_action] += pi
            
        exp_q1 = np.exp(beta * (q_stage1_net - np.max(q_stage1_net)))
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # policy for the second choice
        exp_q2 = np.exp(beta * (q_stage2_mf[state_idx] - np.max(q_stage2_mf[state_idx])))
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # Determine if transition was common or rare
        # Spaceship 0 -> Planet 0 is common, Spaceship 1 -> Planet 1 is common
        is_common = (action_1[trial] == state_idx)
        current_alpha = alpha_common if is_common else alpha_rare

        # action value updating
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += current_alpha * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += current_alpha * delta_stage2

        q_stage1_mf[action_1[trial]] += current_alpha * lambda_ * delta_stage2
        
        last_action = action_1[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```
