Here are 3 new cognitive models that explore alternative mechanisms for explaining the participant's choice behavior, focusing on different ways to capture stickiness, bias, and parameter parsimony.

### Model 1: Stage 1 Bias Model
Given the participant's heavy preference for spaceship 0 (choosing it for the first 129 trials consecutively), this model introduces a specific choice bias parameter for Stage 1. This helps separate true learned value preferences from an inherent baseline bias towards one of the spaceships.

```python
def cognitive_model1(action_1, state, action_2, reward, model_parameters):
    """
    Hybrid model with choice stickiness for both stages and an explicit Stage 1 choice bias.
    bias_1 > 0 indicates an inherent preference for spaceship 0, independent of its value.
    
    Bounds:
    alpha: [0, 1] - learning rate
    beta_1: [0, 10] - inverse temperature for stage 1
    beta_2: [0, 10] - inverse temperature for stage 2
    w: [0, 1] - model-based weight
    lam: [0, 1] - eligibility trace
    p1: [-5, 5] - choice perseverance (stickiness) for stage 1
    p2: [-5, 5] - choice perseverance (stickiness) for stage 2
    bias_1: [-5, 5] - baseline bias for choosing action 0 in Stage 1
    """
    alpha, beta_1, beta_2, w, lam, p1, p2, bias_1 = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    last_action_1 = -1
    last_action_2 = -1

    for trial in range(n_trials):

        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        # Policy for the first choice
        logits_1 = beta_1 * q_stage1_net
        if last_action_1 != -1:
            logits_1[last_action_1] += p1
        logits_1[0] += bias_1  # Add bias for spaceship 0
            
        logits_1 -= np.max(logits_1)
        exp_q1 = np.exp(logits_1)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # Policy for the second choice
        logits_2 = beta_2 * q_stage2_mf[state_idx]
        if last_action_2 != -1:
            logits_2[last_action_2] += p2
            
        logits_2 -= np.max(logits_2)
        exp_q2 = np.exp(logits_2)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # Action value updating
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += alpha * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += alpha * delta_stage2
        q_stage1_mf[action_1[trial]] += alpha * lam * delta_stage2
        
        last_action_1 = action_1[trial]
        last_action_2 = action_2[trial]

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```

### Model 2: Single Temperature Model
This model reduces parameter complexity by assuming the participant has a unified exploration/exploitation trade-off (a single `beta`) across both stages of the task, while still allowing for stage-specific perseveration.

```python

    """
    Hybrid model with a single inverse temperature (beta) for both stages, 
    but separate choice stickiness (p1, p2) for each stage.
    
    Bounds:
    alpha: [0, 1] - learning rate
    beta: [0, 10] - single inverse temperature for both stages
    w: [0, 1] - model-based weight
    lam: [0, 1] - eligibility trace
    p1: [-5, 5] - choice perseverance (stickiness) for stage 1
    p2: [-5, 5] - choice perseverance (stickiness) for stage 2

    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))

    return log_loss
```

### Model 3: Decaying Choice Trace Model
Instead of only repeating the immediate previous action (lag-1 stickiness), this model assumes the participant builds up a "habit" or trace of recent choices that decays exponentially over time. This captures longer-term autocorrelations in behavior.

```python
def cognitive_model3(action_1, state, action_2, reward, model_parameters):
    """
    Hybrid model with exponentially decaying choice traces for stickiness.
    Instead of only sticking to the immediately previous choice, participants 
    have a decaying tendency to repeat recently chosen actions.
    
    Bounds:
    alpha: [0, 1] - learning rate
    beta_1: [0, 10] - inverse temperature for stage 1
    beta_2: [0, 10] - inverse temperature for stage 2
    w: [0, 1] - model-based weight
    lam: [0, 1] - eligibility trace
    p1: [-5, 5] - choice trace weight for stage 1
    p2: [-5, 5] - choice trace weight for stage 2
    tau: [0, 1] - choice trace decay rate (0 = lag-1 stickiness, 1 = permanent habit)
    """
    alpha, beta_1, beta_2, w, lam, p1, p2, tau = model_parameters
    n_trials = len(action_1)
  
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    p_choice_1 = np.zeros(n_trials)
    p_choice_2 = np.zeros(n_trials)
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    
    trace_1 = np.zeros(2)
    trace_2 = np.zeros(2)

    for trial in range(n_trials):

        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        
        q_stage1_net = w * q_stage1_mb + (1 - w) * q_stage1_mf
        
        # Policy for the first choice
        logits_1 = beta_1 * q_stage1_net + p1 * trace_1
        logits_1 -= np.max(logits_1)
        exp_q1 = np.exp(logits_1)
        probs_1 = exp_q1 / np.sum(exp_q1)
        p_choice_1[trial] = probs_1[action_1[trial]]
        state_idx = state[trial]

        # Policy for the second choice
        logits_2 = beta_2 * q_stage2_mf[state_idx] + p2 * trace_2
        logits_2 -= np.max(logits_2)
        exp_q2 = np.exp(logits_2)
        probs_2 = exp_q2 / np.sum(exp_q2)
        p_choice_2[trial] = probs_2[action_2[trial]]

        # Action value updating
        delta_stage1 = q_stage2_mf[state_idx, action_2[trial]] - q_stage1_mf[action_1[trial]]
        q_stage1_mf[action_1[trial]] += alpha * delta_stage1
        
        delta_stage2 = reward[trial] - q_stage2_mf[state_idx, action_2[trial]]
        q_stage2_mf[state_idx, action_2[trial]] += alpha * delta_stage2
        q_stage1_mf[action_1[trial]] += alpha * lam * delta_stage2
        
        # Update choice traces
        trace_1 = trace_1 * tau
        trace_1[action_1[trial]] += 1.0
        
        trace_2 = trace_2 * tau
        trace_2[action_2[trial]] += 1.0

    eps = 1e-10
    log_loss = -(np.sum(np.log(p_choice_1 + eps)) + np.sum(np.log(p_choice_2 + eps)))
    return log_loss
```
