1 · What was run

From the individual GeCCo programs of the participants group GeCCo saw (prompt 1–3 + eval 10–19; only the 8 with individual fits — eval pids 15–19 have none), gemini-3.1-pro-preview (temperature 0, every call logged verbatim in llm_log/, 30 calls) extracted a deduplicated library of 22 cognitive mechanism modules on a fixed RL+WM backbone (block loop, RL softmax, near-deterministic WM policy, probability mixture; 3 backbone parameters). Extraction was gated by seed reconstruction (within 15 BIC of the original program's refit). After a leakage audit (Section 4), a deterministic greedy forward search over the 19 leak-free modules (918 candidates under the task's 6-parameter cap; exhaustive ≈ 18 h, greedy chosen — DECISIONS.md #7) selected one composed program on validation participants 10–19 — group GeCCo's own scoring set. The winner was frozen, then evaluated once on the 15 held-out test participants against three baselines under one seeded protocol (L-BFGS-B, 10 restarts, per-(model, participant) seeds). All LLM calls are Gemini; GPT-5 only generated the original gecco programs.

4 · Within-trial outcome leakage: found, quarantined, disclosed

What happened: the first (unconstrained) search returned outcome_gated_wm_reliance+wm_normalization at validation BIC 299.27 — driven by a module that updates a gate with the current trial's reward before the current choice's likelihood. In RLWM the reward is deterministic given the choice, so this is within-trial outcome leakage, not cognition. It is faithful to the source: seed 3's original GPT-5-evolved program does the same, while the group program does not. An audit flagged 3 of 22 modules (outcome_gated_wm_reliance, set_size_dependent_wm_lapse, load_dependent_wm_arbitration — marked ⚠ in Section 5). All results in this report use the 19 leak-free modules (module_inventory_leakfree.json); the unconstrained artifacts are archived under unconstrained_search/ and reconstruction_results_fulllib.json (there, every reconstruction participant picked the leaky gate and "beat" their ceiling by 130–290 BIC — a measure of how strongly leakage pays). Individual-program refits keep their original mechanisms, leaks included: where a source program leaks, its BIC is inflated against the composed program, which makes the Section 2 result conservative.

6 · Frozen program

def cognitive_model(stimulus, actions, rewards, blocks, set_sizes, model_parameters):
    """
    Composed cognitive model: backbone + Unified WM Update and Decay
    
    Parameters:
    learning_rate: [0, 1] - RL delta-rule learning rate.
    beta: [0, 10] - RL softmax inverse temperature.
    wm_weight: [0, 1] - WM weight in the RL/WM policy mixture.
    unified_wm_update_decay_kappa: [0, 1] - module parameter
    """
    learning_rate, beta, wm_weight, unified_wm_update_decay_kappa = model_parameters
    nA = 3
    log_loss = 0.0
    eps = 1e-10
    for b in np.unique(blocks):
        block_mask = blocks == b
        block_states = stimulus[block_mask]
        block_actions = actions[block_mask]
        block_rewards = rewards[block_mask]
        nS = int(set_sizes[block_mask][0])
        q = (1.0 / nA) * np.ones((nS, nA))
        w = (1.0 / nA) * np.ones((nS, nA))
        w_0 = (1.0 / nA) * np.ones((nS, nA))
        for trial in range(len(block_states)):
            s = int(block_states[trial])
            a = int(block_actions[trial])
            r = float(block_rewards[trial])
            if 0 <= s < nS and 0 <= a < nA:
                rl_values = q[s]
                logits_rl = (beta) * rl_values
                exp_rl = np.exp(logits_rl - np.max(logits_rl))
                probs_rl = exp_rl / np.sum(exp_rl)
                wm_values = w[s]
                logits_wm = (50.0) * wm_values
                exp_wm = np.exp(logits_wm - np.max(logits_wm))
                probs_wm = exp_wm / np.sum(exp_wm)
                mix = wm_weight
                probs = mix * probs_wm + (1.0 - mix) * probs_rl
                log_loss -= np.log(probs[a] + eps)
                delta = r - q[s, a]
                q[s, a] += learning_rate * delta
                unified_wm_update_decay_one_hot = np.zeros(nA)
                unified_wm_update_decay_one_hot[a] = 1.0
                if r > 0.5:
                    w[s, :] = (1.0 - unified_wm_update_decay_kappa) * w[s, :] + unified_wm_update_decay_kappa * unified_wm_update_decay_one_hot
                else:
                    w[s, :] = (1.0 - unified_wm_update_decay_kappa) * w[s, :] + unified_wm_update_decay_kappa * (1.0 / nA)
    return log_loss

7 · Caveats & cross-checks

Honest reading: unlike two-step (where the from-scratch composition was a null vs group GeCCo and only the hybrid-base arm won), the RLWM composed program wins outright — mean ΔBIC -33.8 vs group with 14/15 participants improving, p = 0.0001, and it also beats the canonical baseline and the individual refits. The effect is age-graded (Section 2): most of the gain comes from older adults, which is also where the group program (evolved on young participants) is weakest. Samples are small (8 seeds, 10 validation, 7 + 15 held-out); search was greedy (exhaustive ≈ 18 h); the backbone skips missed trials (~3%) that several original programs index unguarded; the hybrid-base composition arm (canonical model + missing modules) is the designated follow-up, not run here.
