1 · What was run

From the 12 individual GeCCo programs of exactly the participants group GeCCo saw (prompt 1, 2 + eval 4–13), gemini-3.1-pro-preview (temperature 0, every prompt/response logged verbatim in llm_log/) extracted a deduplicated library of 18 cognitive mechanism modules. Extraction was gated: every seed had to be re-composable from its own modules to within 15 BIC of its original program on its own data. A deterministic greedy forward search (6,220 possible candidates under the 8-parameter cap; exhaustive would have taken ~21 h, greedy pre-authorized) selected a single composed program on validation participants 4–13 — the same information budget group GeCCo used. The winner was frozen, then evaluated once on the 21 fully held-out test participants against three baselines under one seeded fitting protocol (L-BFGS-B, 10 restarts, per-(model, participant) seeds).

5 · Frozen composed program

def cognitive_model(action_1, state, action_2, reward, model_parameters):
    """
    Composed cognitive model: backbone + Choice Stickiness, Neutral Q-value Initialization, Unchosen Value Decay to Center
    
    Parameters:
    learning_rate: [0, 1] - TD learning rate.
    beta: [0, 10] - Softmax inverse temperature.
    stickiness: [0, 5] - module parameter
    decay_rate_center_unchosen: [0, 1] - module parameter
    """
    learning_rate, beta, stickiness, decay_rate_center_unchosen = model_parameters
    n_trials = len(action_1)
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2)) + 0.5
    log_loss = 0.0
    eps = 1e-10
    choice_stickiness_last_a1 = -1
    q_stage1_mf = np.zeros(2) + 0.5

    for trial in range(n_trials):
        a1 = int(action_1[trial])
        s_idx = int(state[trial])
        a2 = int(action_2[trial])
        r = float(reward[trial])

        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        stage1_values = q_stage1_mb
        logits_1 = (beta) * stage1_values
        if choice_stickiness_last_a1 != -1:
            logits_1[choice_stickiness_last_a1] += stickiness

        exp_q1 = np.exp(logits_1)
        probs_1 = exp_q1 / np.sum(exp_q1)
        if a1 != -1:
            log_loss -= np.log(probs_1[a1] + eps)

        if s_idx != -1 and a2 != -1:
            stage2_values = q_stage2_mf[s_idx]
            logits_2 = (beta) * stage2_values
            exp_q2 = np.exp(logits_2)
            probs_2 = exp_q2 / np.sum(exp_q2)
            log_loss -= np.log(probs_2[a2] + eps)

        if a1 != -1 and s_idx != -1 and a2 != -1:
            delta_stage1 = q_stage2_mf[s_idx, a2] - q_stage1_mf[a1]
            q_stage1_mf[a1] += learning_rate * delta_stage1
            delta_stage2 = r - q_stage2_mf[s_idx, a2]
            q_stage2_mf[s_idx, a2] += learning_rate * delta_stage2
        if a1 != -1:
            choice_stickiness_last_a1 = a1
        if a1 != -1:
            q_stage1_mf[1 - a1] = (1.0 - decay_rate_center_unchosen) * q_stage1_mf[1 - a1] + decay_rate_center_unchosen * 0.5
        if s_idx != -1 and a2 != -1:
            q_stage2_mf[s_idx, 1 - a2] = (1.0 - decay_rate_center_unchosen) * q_stage2_mf[s_idx, 1 - a2] + decay_rate_center_unchosen * 0.5
            q_stage2_mf[1 - s_idx, :] = (1.0 - decay_rate_center_unchosen) * q_stage2_mf[1 - s_idx, :] + decay_rate_center_unchosen * 0.5

    return log_loss

6 · Caveats & cross-checks

Honest reading: the single-program claim is a null result — one shared program composed from the library generalizes no better than group GeCCo's evolved program (and both sit above the Daw hybrid on these 21 subjects). The library's value shows up at the individual level (Section 3). Also note: greedy (not exhaustive) search; 10-subject validation is noisy (see LOO ranks); the library pipeline consumes information from 12 subjects for extraction + 10 for selection vs group GeCCo's 2 + 10.
