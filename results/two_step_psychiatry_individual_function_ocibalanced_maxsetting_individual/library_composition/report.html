1 · What was run

From the 12 individual GeCCo programs of exactly the participants group GeCCo saw (prompt 1, 2 + eval 4–13), gemini-3.1-pro-preview (temperature 0, every prompt/response logged verbatim in llm_log/) extracted a deduplicated library of 18 cognitive mechanism modules. Extraction was gated: every seed had to be re-composable from its own modules to within 15 BIC of its original program on its own data. A deterministic greedy forward search (6,220 possible candidates under the 8-parameter cap; exhaustive would have taken ~21 h, greedy pre-authorized) selected a single composed program on validation participants 4–13 — the same information budget group GeCCo used. The winner was frozen, then evaluated once on the 21 fully held-out test participants against three baselines under one seeded fitting protocol (L-BFGS-B, 10 restarts, per-(model, participant) seeds). A second composition arm (Section 3) started from the Daw hybrid as base and searched exhaustively over only the library components the hybrid lacks (20 combinations).

3 · Hybrid + missing library components: the best shared program

Second composition arm: instead of building from the bare backbone, start from the Daw hybrid itself and search only over library components the hybrid lacks. The hybrid decomposes exactly into 5 library modules on the backbone (choice_stickiness + eligibility_trace + mb_mf_mixture + separate_learning_rates + separate_stage_betas, 7 parameters); after the inventory's exclusion rules the missing components are just q_init_05, counterfactual_updating, and one of 4 mutually-exclusive decay variants — 20 combinations, searched exhaustively on the same validation participants (4–13).

Winner: hybrid + unchosen_value_decay_center (8 parameters) — unchosen stage-1 actions and unvisited stage-2 states decay toward 0.5. Validation mean BIC 327.47 (base alone 355.84); rank 1 in 7/10 leave-one-out folds, rank 2 otherwise (behind only its own q_init_05 twin).

Hybrid + library winner (Section 3)

def cognitive_model(action_1, state, action_2, reward, model_parameters):
    """
    Composed cognitive model: backbone + Choice Stickiness, Eligibility Trace, MB/MF Mixture, Separate Stage Learning Rates, Separate Stage Betas, Unchosen Value Decay to Center
    
    Parameters:
    learning_rate: [0, 1] - TD learning rate.
    beta: [0, 10] - Softmax inverse temperature.
    stickiness: [0, 5] - module parameter
    lambda_elig: [0, 1] - module parameter
    w: [0, 1] - module parameter
    alpha_2: [0, 1] - module parameter
    beta_2: [0, 10] - module parameter
    decay_rate_center_unchosen: [0, 1] - module parameter
    """
    learning_rate, beta, stickiness, lambda_elig, w, alpha_2, beta_2, decay_rate_center_unchosen = model_parameters
    n_trials = len(action_1)
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2))
    log_loss = 0.0
    eps = 1e-10
    choice_stickiness_last_a1 = -1

    for trial in range(n_trials):
        a1 = int(action_1[trial])
        s_idx = int(state[trial])
        a2 = int(action_2[trial])
        r = float(reward[trial])

        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        stage1_values = w * np.array([0.7 * np.max(q_stage2_mf[0]) + 0.3 * np.max(q_stage2_mf[1]), 0.3 * np.max(q_stage2_mf[0]) + 0.7 * np.max(q_stage2_mf[1])]) + (1.0 - w) * q_stage1_mf
        logits_1 = (beta) * stage1_values
        if choice_stickiness_last_a1 != -1:
            logits_1[choice_stickiness_last_a1] += stickiness

        exp_q1 = np.exp(logits_1)
        probs_1 = exp_q1 / np.sum(exp_q1)
        if a1 != -1:
            log_loss -= np.log(probs_1[a1] + eps)

        if s_idx != -1 and a2 != -1:
            stage2_values = q_stage2_mf[s_idx]
            logits_2 = (beta_2) * stage2_values
            exp_q2 = np.exp(logits_2)
            probs_2 = exp_q2 / np.sum(exp_q2)
            log_loss -= np.log(probs_2[a2] + eps)

        if a1 != -1 and s_idx != -1 and a2 != -1:
            delta_stage1 = q_stage2_mf[s_idx, a2] - q_stage1_mf[a1]
            q_stage1_mf[a1] += learning_rate * delta_stage1
            delta_stage2 = r - q_stage2_mf[s_idx, a2]
            q_stage2_mf[s_idx, a2] += learning_rate * delta_stage2
            q_stage1_mf[a1] += learning_rate * lambda_elig * delta_stage2
            q_stage2_mf[s_idx, a2] += (alpha_2 - learning_rate) * delta_stage2

        if a1 != -1:
            choice_stickiness_last_a1 = a1
        if a1 != -1:
            q_stage1_mf[1 - a1] = (1.0 - decay_rate_center_unchosen) * q_stage1_mf[1 - a1] + decay_rate_center_unchosen * 0.5
        if s_idx != -1 and a2 != -1:
            q_stage2_mf[s_idx, 1 - a2] = (1.0 - decay_rate_center_unchosen) * q_stage2_mf[s_idx, 1 - a2] + decay_rate_center_unchosen * 0.5
            q_stage2_mf[1 - s_idx, :] = (1.0 - decay_rate_center_unchosen) * q_stage2_mf[1 - s_idx, :] + decay_rate_center_unchosen * 0.5

    return log_loss

From-scratch composed winner (Section 2)

def cognitive_model(action_1, state, action_2, reward, model_parameters):
    """
    Composed cognitive model: backbone + Choice Stickiness, Neutral Q-value Initialization, Unchosen Value Decay to Center
    
    Parameters:
    learning_rate: [0, 1] - TD learning rate.
    beta: [0, 10] - Softmax inverse temperature.
    stickiness: [0, 5] - module parameter
    decay_rate_center_unchosen: [0, 1] - module parameter
    """
    learning_rate, beta, stickiness, decay_rate_center_unchosen = model_parameters
    n_trials = len(action_1)
    transition_matrix = np.array([[0.7, 0.3], [0.3, 0.7]])
    q_stage1_mf = np.zeros(2)
    q_stage2_mf = np.zeros((2, 2)) + 0.5
    log_loss = 0.0
    eps = 1e-10
    choice_stickiness_last_a1 = -1
    q_stage1_mf = np.zeros(2) + 0.5

    for trial in range(n_trials):
        a1 = int(action_1[trial])
        s_idx = int(state[trial])
        a2 = int(action_2[trial])
        r = float(reward[trial])

        max_q_stage2 = np.max(q_stage2_mf, axis=1)
        q_stage1_mb = transition_matrix @ max_q_stage2
        stage1_values = q_stage1_mb
        logits_1 = (beta) * stage1_values
        if choice_stickiness_last_a1 != -1:
            logits_1[choice_stickiness_last_a1] += stickiness

        exp_q1 = np.exp(logits_1)
        probs_1 = exp_q1 / np.sum(exp_q1)
        if a1 != -1:
            log_loss -= np.log(probs_1[a1] + eps)

        if s_idx != -1 and a2 != -1:
            stage2_values = q_stage2_mf[s_idx]
            logits_2 = (beta) * stage2_values
            exp_q2 = np.exp(logits_2)
            probs_2 = exp_q2 / np.sum(exp_q2)
            log_loss -= np.log(probs_2[a2] + eps)

        if a1 != -1 and s_idx != -1 and a2 != -1:
            delta_stage1 = q_stage2_mf[s_idx, a2] - q_stage1_mf[a1]
            q_stage1_mf[a1] += learning_rate * delta_stage1
            delta_stage2 = r - q_stage2_mf[s_idx, a2]
            q_stage2_mf[s_idx, a2] += learning_rate * delta_stage2
        if a1 != -1:
            choice_stickiness_last_a1 = a1
        if a1 != -1:
            q_stage1_mf[1 - a1] = (1.0 - decay_rate_center_unchosen) * q_stage1_mf[1 - a1] + decay_rate_center_unchosen * 0.5
        if s_idx != -1 and a2 != -1:
            q_stage2_mf[s_idx, 1 - a2] = (1.0 - decay_rate_center_unchosen) * q_stage2_mf[s_idx, 1 - a2] + decay_rate_center_unchosen * 0.5
            q_stage2_mf[1 - s_idx, :] = (1.0 - decay_rate_center_unchosen) * q_stage2_mf[1 - s_idx, :] + decay_rate_center_unchosen * 0.5

    return log_loss

7 · Caveats & cross-checks

Honest reading: composing a shared program from scratch is a null result vs group GeCCo (Section 2). But a theory-guided base changes the picture: the Daw hybrid plus a single library component beats group GeCCo decisively (p = 0.0025) and improves on the hybrid by -16.6 mean BIC — though that gain is carried by about half the participants (W/L 11/10, Wilcoxon p = 0.082); for the rest the extra mechanism is dead weight, consistent with the individual-differences story of Section 4. Also note: the from-scratch arm used greedy (not exhaustive) search; the hybrid-base arm is exhaustive over its 20 combinations; 10-subject validation is noisy (see LOO ranks); the library pipeline consumes information from 12 subjects for extraction + 10 for selection vs group GeCCo's 2 + 10.
